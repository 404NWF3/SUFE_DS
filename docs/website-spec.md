# SUFE DS 资料共享网站规格

版本：v0.2

日期：2026-11-07

目标地址：[上财学习资料库](https://404nwf3.github.io/SUFE_DS/)

本版按最新需求收窄为一个好看、轻量的 GitHub Pages 网站：只渲染 Markdown，其余格式提供原文件下载或原站入口。现有课程目录仍是唯一内容来源，不复制资料到网站工程，也不制作 PDF、Word、音频等格式的预览。

## 页面与视觉

采用暖白背景、深绿色文字、淡绿色强调色与纸张式排版。首页以精选笔记的书页构图介绍资料库，同时提供搜索、实际收录数量、课程入口、精选阅读、考试专题和贡献入口。桌面与手机均能使用。

| 页面 | 路径 | 功能 |
| --- | --- | --- |
| 首页 | `/SUFE_DS/` | 介绍、搜索、课程入口、精选笔记、考试专题 |
| 课程目录 | `/SUFE_DS/courses/` | 学科筛选、课程名称搜索 |
| 课程页 | `/SUFE_DS/courses/{id}/` | 课程说明、笔记、其他文件及下载 |
| 全部资料 | `/SUFE_DS/resources/` | 按关键词、笔记或下载类型、格式筛选，分页 |
| 笔记阅读页 | `/SUFE_DS/notes/{id}/` | Markdown 正文、数学公式、章节目录、原文及下载 |
| 关于 | `/SUFE_DS/about/` | 项目缘起、使用方法、贡献指南与外部学习入口 |

## 内容规则

- 构建时扫描 Git 跟踪文件，课程与学科映射由 `site/src/config.mjs` 配置。
- Markdown 生成静态 HTML，支持 GFM、公式、目录、脚注、callout、内部链接与 Obsidian 图片嵌入。
- 非空课程 README 显示为课程说明，不重复计入笔记数量。空白 Markdown、辅助图片、编译产物和编辑器缓存不作为独立笔记。
- PDF、Word、PPT、表格、音频、代码、压缩包、notebook 等只提供原文件入口；`.url` 解析为外部链接。
- 原文件及笔记插图指向 GitHub 原仓库，本次构建的提交号用于固定来源版本。下载行为遵循浏览器：部分文件可能在新标签打开后通过浏览器保存。
- 已缺失的图片明确显示缺失提示；原文不支持的公式保留原式并记录构建报告，不擅自修改学习内容。
- 网站搜索匹配标题、路径、课程名和 Markdown 摘要，不承诺 PDF 全文检索。

## 技术与维护

使用 Node.js 静态生成脚本、原生 CSS 和少量浏览器 JavaScript。Markdown 通过 remark/rehype 渲染，公式由 KaTeX 在构建时生成；资料浏览不依赖后台。后续增加的公开学习问答使用独立托管后端，范围与数据规则见 [问答规格](ai-assistant-spec.md)。

网站工程位于 `site/`，发布产物为 `site/dist/`；依赖、产物与检查报告不进入 Git。GitHub Actions 稀疏检出网站代码、Markdown 和外链快捷方式，读取 Git 索引生成其他格式的下载清单。原始资料不进入发布产物。

`main` 更新触发测试、构建、内部链接检查和 GitHub Pages 发布；Pull Request 只检查。Pages 来源设为 GitHub Actions。运行与维护步骤见 [网站说明](../site/README.md)。

## 验收标准

1. 首页有真实课程和精选笔记，搜索与导航可用。
2. 课程和资料列表支持筛选、分页、空结果提示；搜索状态写入 URL。
3. 所有收录的 Markdown 都生成可直接访问、刷新和分享的阅读页。
4. 公式、表格和代码在手机上可阅读，长公式和表格在局部滚动。
5. 非 Markdown 文件只提供下载渠道，页面不包含文件预览器。
6. 构建产物不含原始资料副本，下载与图片来自原仓库。
7. 自动检查内部页面链接、资源 ID、源文件误复制与站点大小。
8. 发布后在真实 GitHub Pages 地址检查首页、笔记页与下载入口。
