# 公开学习问答与 DeepSeek 助手

日期：2026-11-07

所有提问、AI 回答和同学的补充都公开，组成可分享的讨论串。前端继续发布到 GitHub Pages；独立托管的 Worker 和 D1 数据库保存讨论并调用 DeepSeek，维护者不需要另外购买或运维服务器。

## 使用方式

- 网站增加「学习问答」入口，笔记页可带着当前笔记进入提问。
- 任何访客可浏览、按课程筛选和搜索问题；发言时输入昵称及学习区邀请码。
- 发布前明确显示「问题和回复将公开」，提交即创建公开讨论。
- 新问题可以邀请 AI 回答；同学可以继续补充，也可以邀请 AI 结合讨论继续解释。
- 助手通过搜索笔记、读取原文两个工具查阅本站 Markdown，并附实际读取的来源。其他格式仍只提供下载，不读取或转换。
- 管理员使用独立管理码进入，能够隐藏讨论及回复。昵称只是显示名称，不代表已验证的学生身份。

## 数据与服务

- DeepSeek 密钥只保存在服务端加密配置中；公共页面不接收、不存储此密钥。
- 数据库存储公开讨论、回复、来源、生成状态和用量计数；不保存密钥、明文邀请码或原始 IP。
- 前端保存短期发言凭证和昵称，可退出；后台用签名令牌区分发言者和管理员。
- 公开读接口与受限写接口分开。邀请码、请求体长度、发言频率、每人及全站每日 AI 次数共同控制访问。
- 初始全站每日最多 100 次 AI 调用任务，每个发言凭证每日 20 次；每项任务的工具轮次、上下文和输出长度也有上限。额度按北京时间重置，可由维护者调整。昵称和邀请码不是实名验证，凭证额度不等同于严格的个人额度。
- 只生成笔记标题、目录、摘要和原路径的索引。正文按需从固定提交版本的 GitHub 原文件读取，不另存资料副本。
- 模型异常或超时保留已发布问题，明确显示失败状态；不会编造 AI 回答，也不会自动无限重试。

## 验收

1. 手机和桌面可以浏览、提问、回复、打开独立讨论链接。
2. 不同访客能读到同一份服务端保存的公开讨论。
3. 无有效凭证不能发布、触发 AI 或执行管理操作。
4. AI 只能调用受控的资料工具，不能执行代码或任意访问用户指定网址。
5. 来源指向实际读取的原文；找不到资料时明确说明依据不足。
6. 额度扣减与 AI 任务锁在服务端生效，重复点击不会并发重复生成。
7. 对用户和模型输出安全渲染，禁止脚本和任意图片执行或加载。
8. 用真实 DeepSeek 请求和两个独立访客会话完成线上验证后，才报告正式接通。

## 接口依据

- [DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)
- [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)
- [Cloudflare D1 批量语句](https://developers.cloudflare.com/d1/worker-api/d1-database/)

模型名称通过服务端环境变量配置，按当前官方文档默认使用 `deepseek-flash`。
