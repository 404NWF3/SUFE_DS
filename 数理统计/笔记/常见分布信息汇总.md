# 数理统计常见分布信息汇总
> **参数约定：**
>
> - **指数分布 $\text{Exp}(\theta)$**：p.d.f. $f(x;\theta)=\theta e^{-\theta x}$（**rate 参数**），$E[X]=1/\theta$，$\text{Var}(X)=1/\theta^2$。
>   ⚠️ 凡题目写 $\text{Exp}(1/\theta)$（均值为 $\theta$），即 $f(x;\theta)=\frac1\theta e^{-x/\theta}$，是同一分布族的另一种参数化，本篇单列一行对照。
> - **Gamma 分布 $\Gamma(\alpha,\beta)$**：p.d.f. $\frac{1}{\Gamma(\alpha)\beta^\alpha}x^{\alpha-1}e^{-x/\beta}$，$E[X]=\alpha\beta$，$\text{Var}(X)=\alpha\beta^2$。
> - **正态 $N(\mu,\sigma^2)$**：$\sigma^2$ 为方差参数（$\sigma>0$）。
>
> **符号约定**：样本 $X_1,\ldots,X_n\stackrel{iid}{\sim}f(x;\theta)$；$\bar X=\frac1n\sum X_i$；$S^2=\frac1{n-1}\sum(X_i-\bar X)^2$；$X_{(1)}=\min X_i$，$X_{(n)}=\max X_i$，$Q_2$ 为样本中位数。
> **CSS** = Complete Sufficient Statistic（完备充分统计量）。**MSS** = Minimal Sufficient Statistic（最小充分统计量）。

## 一、离散单参数分布

### 1. Bernoulli$(\theta)$，$\theta\in(0,1)$

p.m.f. $f(x;\theta)=\theta^x(1-\theta)^{1-x}$，$x\in\{0,1\}$。$E[X]=\theta$，$\text{Var}(X)=\theta(1-\theta)$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\bar X$（若约束 $\theta\le 1/3$ 则 $\hat\theta=\min\{\bar X,1/3\}$） |
| **Fisher 信息量** | $I(\theta)=\dfrac{1}{\theta(1-\theta)}$ |
| **充分统计量** | $T=\sum X_i\sim\text{Bin}(n,\theta)$，**CSS ✓** |
| **最小充分** | $\sum X_i$（=MLE 自身，故为 MSS） |
| **MVUE（$\theta$）** | $\bar X$（无偏且达 RCB $\frac{\theta(1-\theta)}{n}=\frac1{nI(\theta)}$，有效，故 MVUE） |
| **MVUE（$g(\theta)=\theta(1-\theta)$）** | $\dfrac{n}{n-1}\bar X(1-\bar X)=\dfrac{Y(n-Y)}{n(n-1)}$，$Y=\sum X_i$ |
| **MVUE（$g(\theta)=\theta(1+\theta)$，$\text{Bin}(2,\theta)$ 抽样）** | 见期末总结 HW7 P7 |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\ln\tfrac{\theta}{1-\theta}}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{0}_{H(x)}+\underbrace{\ln(1-\theta)}_{q(\theta)}\Big\},\quad S=\{0,1\}.$$

- $p'=\frac1{\theta(1-\theta)}$，$p''=-\frac{1-2\theta}{\theta^2(1-\theta)^2}$；$q'=-\frac1{1-\theta}$，$q''=-\frac1{(1-\theta)^2}$。
- $E[K(X)]=E[X]=-\dfrac{q'}{p'}=-\dfrac{-1/(1-\theta)}{1/[\theta(1-\theta)]}=\theta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{\frac{-(1-2\theta)}{\theta^2(1-\theta)^2}\cdot\frac{-1}{1-\theta}-\frac{-1}{(1-\theta)^2}\cdot\frac1{\theta(1-\theta)}}{1/[\theta(1-\theta)]^3}=\theta(1-\theta)$ ✓

> ⭐ 充分完备统计量 $Y_1=\sum X_i$ 的矩（Hogg Thm 7.5.1）：$E(Y_1)=n\theta$，$\text{Var}(Y_1)=n\theta(1-\theta)$，与 $\text{Bin}(n,\theta)$ 一致。

### 2. Binomial$(m,\theta)$（$m$ 已知），$\theta\in(0,1)$

p.m.f. $f(x;\theta)=\binom{m}{x}\theta^x(1-\theta)^{m-x}$，$x=0,\ldots,m$。$E[X]=m\theta$，$\text{Var}(X)=m\theta(1-\theta)$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\bar X/m$（$\sum X_i\sim\text{Bin}(mn,\theta)$） |
| **Fisher 信息量** | 单观测 $I(\theta)=\dfrac{m}{\theta(1-\theta)}$ |
| **充分统计量** | $T=\sum X_i\sim\text{Bin}(mn,\theta)$，**CSS ✓** |
| **最小充分** | $\sum X_i$ |
| **MVUE（$\theta$）** | $\bar X/m$（无偏，达 RCB $\frac{\theta(1-\theta)}{mn}=\frac1{nI(\theta)}$） |
| **MVUE（$g(\theta)=\theta(1+\theta)$）** | 见期末总结 HW7 P7：$\hat g=\dfrac{Y_1^2}{2n(2n-1)}+\dfrac{(n-1)Y_1}{n(2n-1)}$，$Y_1=\sum X_i$（此处 $m=2$） |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\ln\tfrac{\theta}{1-\theta}}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{\ln\binom{m}{x}}_{H(x)}+\underbrace{m\ln(1-\theta)}_{q(\theta)}\Big\},\quad S=\{0,1,\ldots,m\}.$$

- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-m/(1-\theta)}{1/[\theta(1-\theta)]}=m\theta$ ✓
- $\text{Var}(K(X))=m\theta(1-\theta)$ ✓

### 3. 几何分布 $f(x;\theta)=(1-\theta)^x\theta$，$x=0,1,2,\ldots$，$\theta\in(0,1)$

即"首次成功前的失败次数"。$E[X]=\frac{1-\theta}{\theta}$，$\text{Var}(X)=\frac{1-\theta}{\theta^2}$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\dfrac{1}{\bar X+1}=\dfrac{n}{\sum X_i+n}$ |
| **Fisher 信息量** | $I(\theta)=\dfrac{1}{\theta^2(1-\theta)}$ |
| **充分统计量** | $T=\sum X_i$，**CSS ✓**（正则指数族，期末总结 HW7 P1） |
| **最小充分** | $\sum X_i$ |
| **MVUE（$\theta$）** | 需 Rao-Blackwell：取 $U=I\{X_1=0\}$（无偏，$E[U]=\theta$），$E[U\mid\sum X_i=t]=\dfrac{?}{?}$；指数族形式给出 $E[U|T]$ 经条件分布可算，但期末总结未列闭式。⭐ 关键：完备充分统计量是 $\sum X_i$，故 MVUE 必为 $\sum X_i$ 的函数。 |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\ln(1-\theta)}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{0}_{H(x)}+\underbrace{\ln\theta}_{q(\theta)}\Big\},\quad S=\{0,1,2,\ldots\}.$$

> ⚠️ 注意 $p(\theta)=\ln(1-\theta)$ 是 $\theta$ 的**单调减**函数（与 Bernoulli/Binomial 的 $\ln\frac{\theta}{1-\theta}$ 增不同），写 MLR 时不影响 UMP 结论的方向判断。

- $p'=-\frac1{1-\theta}$，$p''=-\frac1{(1-\theta)^2}$；$q'=\frac1\theta$，$q''=-\frac1{\theta^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{1/\theta}{-1/(1-\theta)}=\dfrac{1-\theta}{\theta}$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{\frac{-1}{(1-\theta)^2}\cdot\frac1\theta-\frac{-1}{\theta^2}\cdot\frac{-1}{1-\theta}}{-1/(1-\theta)^3}=\dfrac{1-\theta}{\theta^2}$ ✓

### 4. 负二项分布 $f(x;\theta)=\binom{x+r-1}{x}(1-\theta)^r\theta^x$，$x=0,1,2,\ldots$（$r$ 已知）

$E[X]=\frac{r\theta}{1-\theta}$，$\text{Var}(X)=\frac{r\theta}{(1-\theta)^2}$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\dfrac{\bar X}{\bar X+r}$ |
| **Fisher 信息量** | $I(\theta)=\dfrac{r}{\theta(1-\theta)^2}$ |
| **充分统计量** | $T=\sum X_i$，**CSS ✓**（期末总结 HW7 P1） |
| **最小充分** | $\sum X_i$ |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\ln\theta}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{\ln\binom{x+r-1}{x}+r\ln(1-\theta)\text{ 中非 }x\text{ 部分需归 }q}_{H(x)\text{ 与 }q(\theta)}\Big\}.$$
准确写法：$p(\theta)=\ln\theta$，$K(x)=x$，$H(x)=\ln\binom{x+r-1}{x}$，$q(\theta)=r\ln(1-\theta)$，$S=\{0,1,2,\ldots\}$。

- $p'=\frac1\theta$，$p''=-\frac1{\theta^2}$；$q'=-\frac r{1-\theta}$，$q''=-\frac r{(1-\theta)^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-r/(1-\theta)}{1/\theta}=\dfrac{r\theta}{1-\theta}$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{(-1/\theta^2)(-r/(1-\theta))-(-r/(1-\theta)^2)(1/\theta)}{1/\theta^3}=\dfrac{r\theta}{(1-\theta)^2}$ ✓

> 💡 几何分布是负二项 $r=1$ 的特例；上面两条 $E[K]$、$\text{Var}(K)$ 取 $r=1$ 即还原几何的结论。

### 5. Poisson$(\theta)$，$\theta>0$

p.m.f. $f(x;\theta)=\frac{\theta^x e^{-\theta}}{x!}$，$x=0,1,2,\ldots$。$E[X]=\theta$，$\text{Var}(X)=\theta$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\bar X$ |
| **Fisher 信息量** | $I(\theta)=\dfrac1\theta$ |
| **充分统计量** | $T=\sum X_i\sim\text{Po}(n\theta)$，**CSS ✓** |
| **最小充分** | $\sum X_i$（=MLE，故 MSS） |
| **MVUE（$\theta$）** | $\bar X$（无偏，达 RCB $\frac\theta n=\frac1{nI(\theta)}$，有效） |
| **MVUE（$g(\theta)=e^{-\theta}=P(X_1=0)$）** | $\big(\frac{n-1}{n}\big)^{\sum X_i}$（$n$ 样本，见期末总结 Ass6 P7：$\varphi(T)=(2/3)^T$ 为 $n=3$ 之例） |
| **MVUE（$g(\theta)=P(X_1=k)=\frac{\theta^k e^{-\theta}}{k!}$）** | $\binom{\sum X_i}{k}\big(\frac1n\big)^k\big(1-\frac1n\big)^{\sum X_i-k}$（HW7 P6） |
| **MVUE（$g(\theta)=e^{-2\theta}$，单样本 $X_1$）** | $(-1)^{X_1}$（期末总结 14.1 例4，$X_1$ 自身完备充分） |
| **MVUE（$g(\theta)=\theta^2$，$n=2$）** | $X_1X_2$（Ass5 P6，无偏但非有效，效率 $\frac{2\theta}{2\theta+1}$） |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\ln\theta}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{-\ln(x!)}_{H(x)}+\underbrace{-\theta}_{q(\theta)}\Big\},\quad S=\{0,1,2,\ldots\}.$$

- $p'=\frac1\theta$，$p''=-\frac1{\theta^2}$；$q'=-1$，$q''=0$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-1}{1/\theta}=\theta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{(-1/\theta^2)(-1)-0}{1/\theta^3}=\theta$ ✓（期末总结 13.5 已数值核验）

> 🎯 Poisson 是考 MVUE 的高频分布：$e^{-\theta}$、$P(X=k)$、$\theta^2$ 都有标准 Rao-Blackwell 套路。

## 二、连续单参数分布

### 6. $N(\theta,\sigma_0^2)$（$\sigma_0^2$ 已知）

p.d.f. $f(x;\theta)=\frac1{\sqrt{2\pi}\sigma_0}e^{-(x-\theta)^2/(2\sigma_0^2)}$。$E[X]=\theta$，$\text{Var}(X)=\sigma_0^2$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\bar X$ |
| **Fisher 信息量** | $I(\theta)=\dfrac1{\sigma_0^2}$（常数，location family） |
| **充分统计量** | $T=\sum X_i$（或 $\bar X$），**CSS ✓** |
| **最小充分** | $\bar X$（=MLE，故 MSS） |
| **MVUE（$\theta$）** | $\bar X$（无偏，达 RCB $\frac{\sigma_0^2}{n}=\frac1{nI(\theta)}$，有效） |
| **MVUE（$g(\theta)=\theta^2$）** | $\bar X^2-\dfrac{\sigma_0^2}{n}$（期末总结 14.1 例2） |
| **MVUE（$g(\theta)=P(X\le c)=\Phi(c-\theta)$）** | $\Phi\!\Big(\sqrt{\dfrac n{n-1}}(c-\bar X)\Big)$（期末总结 14.1 例3） |
| **MVUE（$g(\theta)=a\theta^2+b\theta+c$）** | $a\bar X^2+b\bar X+\Big(c-\dfrac{a\sigma_0^2}{n}\Big)$（HW7 P5） |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\theta/\sigma_0^2}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{-x^2/(2\sigma_0^2)}_{H(x)}+\underbrace{-\tfrac{\theta^2}{2\sigma_0^2}-\tfrac12\ln(2\pi\sigma_0^2)}_{q(\theta)}\Big\},\quad S=\mathbb R.$$

- $p'=\frac1{\sigma_0^2}$，$p''=0$；$q'=-\frac\theta{\sigma_0^2}$，$q''=-\frac1{\sigma_0^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-\theta/\sigma_0^2}{1/\sigma_0^2}=\theta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{0-(-1/\sigma_0^2)(1/\sigma_0^2)}{1/\sigma_0^6}=\sigma_0^2$ ✓

> 💡 Basu 定理经典场：$T=\bar X$ 完备充分，$A=S^2$（或 $X_1-\bar X$ 等）从属，故 $\bar X\perp S^2$、$\bar X\perp(X_1-\bar X,\ldots,X_n-\bar X)$。

### 7. $N(\mu_0,\theta)$（$\mu_0$ 已知，$\theta=\sigma^2>0$）

p.d.f. $f(x;\theta)=\frac1{\sqrt{2\pi\theta}}e^{-(x-\mu_0)^2/(2\theta)}$。参数是**方差** $\theta$。$E[X]=\mu_0$，$\text{Var}(X)=\theta$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\dfrac1n\sum(X_i-\mu_0)^2$ |
| **Fisher 信息量** | $I(\theta)=\dfrac1{2\theta^2}$ |
| **充分统计量** | $T=\sum(X_i-\mu_0)^2$，**CSS ✓** |
| **最小充分** | $\sum(X_i-\mu_0)^2$（=MLE 的核，故 MSS） |
| **MVUE（$\theta$）** | $\dfrac1n\sum(X_i-\mu_0)^2$（无偏：$\sum(X_i-\mu_0)^2/\theta\sim\chi^2(n)$，$E[T]=n\theta$；达 RCB $\frac{2\theta^2}{n}=\frac1{nI(\theta)}$，有效） |
| **$S^2$ 的有效性** | $\text{Var}(S^2)=\frac{2\theta^2}{n-1}$，效率 $=\dfrac{n-1}{n}$（Ass5 P5） |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{-\tfrac1{2\theta}}_{p(\theta)}\underbrace{(x-\mu_0)^2}_{K(x)}+\underbrace{-\tfrac12\ln(2\pi)}_{H(x)}+\underbrace{-\tfrac12\ln\theta}_{q(\theta)}\Big\},\quad S=\mathbb R.$$

- $p'=\frac1{2\theta^2}$，$p''=-\frac1{\theta^3}$；$q'=-\frac1{2\theta}$，$q''=\frac1{2\theta^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-1/(2\theta)}{1/(2\theta^2)}=\theta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{(-1/\theta^3)(-1/(2\theta))-(1/(2\theta^2))(1/(2\theta^2))}{1/(8\theta^6)}=\dfrac{\frac1{2\theta^4}-\frac1{4\theta^4}}{1/(8\theta^6)}=2\theta^2$ ✓
  （与 $\frac{(X-\mu_0)^2}{\theta}\sim\chi^2(1)$，方差 $2\theta^2$ 一致。）

> 🎐 期末总结 13.5 已用此例数值核验 Hogg Thm 7.5.1：$E(Y_1)=n\theta$，$\text{Var}(Y_1)=2n\theta^2$。

### 8. 指数分布 $\text{Exp}(\theta)$（**rate 参数**），$\theta>0$

p.d.f. $f(x;\theta)=\theta e^{-\theta x}$，$x>0$。$E[X]=1/\theta$，$\text{Var}(X)=1/\theta^2$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\dfrac1{\bar X}=\dfrac{n}{\sum X_i}$（**有偏**：$E[\hat\theta]\ne\theta$） |
| **Fisher 信息量** | $I(\theta)=\dfrac1{\theta^2}$（期末总结 Ass5 P2 三种方法算得） |
| **充分统计量** | $T=\sum X_i\sim\Gamma(n,1/\theta)$，**CSS ✓** |
| **最小充分** | $\sum X_i$（=MLE 的核，MSS） |
| **MVUE（$\theta$）** | ⚠️ rate 参数化下 $\hat\theta=1/\bar X$ 有偏；纠偏得 $\tilde\theta=\dfrac{n-1}{\sum X_i}$（因 $\sum X_i\sim\Gamma(n,1/\theta)$，$E[1/\sum X_i]=\frac{\theta}{n-1}$）。期末总结 Ass5 P2 在 mean 参数化下讨论，此处 rate 参数化 MVUE 为 $\frac{n-1}{\sum X_i}$。 |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{-\theta}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{0}_{H(x)}+\underbrace{\ln\theta}_{q(\theta)}\Big\},\quad S=(0,\infty).$$

- $p'=-1$，$p''=0$；$q'=\frac1\theta$，$q''=-\frac1{\theta^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{1/\theta}{-1}=\dfrac1\theta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{0-(-1/\theta^2)(-1)}{(-1)^3}=\dfrac1{\theta^2}$ ✓

> ⚠️ **参数化陷阱**：rate 版 $\hat\theta=1/\bar X$ 有偏；mean 版（下一条）$\hat\theta=\bar X$ 无偏。期末总结在 Ass5 P2 明确提示了这一勘误。

### 9. 指数分布 $\text{Exp}(1/\theta)$（**mean 参数**，均值为 $\theta$），$\theta>0$

p.d.f. $f(x;\theta)=\dfrac1\theta e^{-x/\theta}$，$x>0$。$E[X]=\theta$，$\text{Var}(X)=\theta^2$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=\bar X$（**无偏**：$E[\hat\theta]=\theta$） |
| **Fisher 信息量** | $I(\theta)=\dfrac1{\theta^2}$ |
| **充分统计量** | $T=\sum X_i\sim\Gamma(n,\theta)$，**CSS ✓** |
| **最小充分** | $\sum X_i$ |
| **MVUE（$\theta$）** | $\bar X$（无偏，达 RCB $\frac{\theta^2}{n}=\frac1{nI(\theta)}$，有效，故 MVUE） |

**正则指数族分解**（把上条的 $\theta$ 换成 $1/\theta$ 即得，此处 $\theta$ 是尺度参数）：
$$f(x;\theta)=\exp\Big\{\underbrace{-\tfrac1\theta}_{p(\theta)}\underbrace{x}_{K(x)}+\underbrace{0}_{H(x)}+\underbrace{-\ln\theta}_{q(\theta)}\Big\},\quad S=(0,\infty).$$

- $p'=\frac1{\theta^2}$，$p''=-\frac2{\theta^3}$；$q'=-\frac1\theta$，$q''=\frac1{\theta^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-1/\theta}{1/\theta^2}=\theta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{(-2/\theta^3)(-1/\theta)-(1/\theta^2)(1/\theta^2)}{1/\theta^6}=\dfrac{2/\theta^4-1/\theta^4}{1/\theta^6}=\theta^2$ ✓

> 💡 $\text{Exp}(1/\theta)=\Gamma(1,\theta)$，是下一条 Gamma 在 $\alpha_0=1$ 的特例。

### 10. Gamma 分布 $\Gamma(\alpha_0,\beta)$（**$\alpha_0$ 已知，尺度 $\beta$ 未知**），$\beta>0$

p.d.f. $f(x;\beta)=\dfrac1{\Gamma(\alpha_0)\beta^{\alpha_0}}x^{\alpha_0-1}e^{-x/\beta}$，$x>0$。$E[X]=\alpha_0\beta$，$\text{Var}(X)=\alpha_0\beta^2$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\beta=\dfrac{\bar X}{\alpha_0}=\dfrac{\sum X_i}{n\alpha_0}$ |
| **Fisher 信息量** | $I(\beta)=\dfrac{\alpha_0}{\beta^2}$ |
| **充分统计量** | $T=\sum X_i\sim\Gamma(n\alpha_0,\beta)$，**CSS ✓** |
| **最小充分** | $\sum X_i$ |
| **MVUE（$\beta$）** | $\dfrac{\bar X}{\alpha_0}=\dfrac{\sum X_i}{n\alpha_0}$（无偏：$E[\sum X_i]=n\alpha_0\beta$；达 RCB $\frac{\beta^2}{n\alpha_0}=\frac1{nI(\beta)}$，有效，故 MVUE） |

**正则指数族分解**：
$$f(x;\beta)=\exp\Big\{\underbrace{-\tfrac1\beta}_{p(\beta)}\underbrace{x}_{K(x)}+\underbrace{(\alpha_0-1)\ln x-\ln\Gamma(\alpha_0)}_{H(x)}+\underbrace{-\alpha_0\ln\beta}_{q(\beta)}\Big\},\quad S=(0,\infty).$$

- $p'=\frac1{\beta^2}$，$p''=-\frac2{\beta^3}$；$q'=-\frac{\alpha_0}{\beta}$，$q''=\frac{\alpha_0}{\beta^2}$。
- $E[K(X)]=-\dfrac{q'}{p'}=-\dfrac{-\alpha_0/\beta}{1/\beta^2}=\alpha_0\beta$ ✓
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{(-2/\beta^3)(-\alpha_0/\beta)-(\alpha_0/\beta^2)(1/\beta^2)}{1/\beta^6}=\dfrac{2\alpha_0/\beta^4-\alpha_0/\beta^4}{1/\beta^6}=\alpha_0\beta^2$ ✓

> 🎯 期末总结 HW7 P2 是 $\Gamma(4,\theta)$（即 $\alpha_0=4$、尺度记 $\theta$）：完备充分统计量 $\sum X_i$，MVUE $\hat\theta_{\text{MVUE}}=\frac{\sum X_i}{4n}=\frac{\bar X}{4}$；HW7 P3（$N(\mu_0,\theta)$）同构。Ass6 P3 是 $\Gamma(2,\theta)$（$\alpha_0=2$）：MLE $\hat\theta=\bar X/2$，$I(\theta)=2/\theta^2$，达 RCB。

### 11. Gamma 分布 $\Gamma(\theta,\beta_0)$（**$\beta_0$ 已知，形状 $\theta$ 未知**），$\theta>0$

p.d.f. $f(x;\theta)=\dfrac1{\Gamma(\theta)\beta_0^\theta}x^{\theta-1}e^{-x/\beta_0}$，$x>0$。$E[X]=\theta\beta_0$，$\text{Var}(X)=\theta\beta_0^2$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta$ 无显示解（需解 $\ln\theta-\psi(\theta)=\ln\bar X-\overline{\ln x}-\ln\beta_0$，$\psi$ 为 digamma） |
| **Fisher 信息量** | $I(\theta)=\psi'(\theta)$（trigamma 函数，无初等闭式） |
| **充分统计量** | $T=\sum\ln X_i$，**CSS ✓** |
| **最小充分** | $\sum\ln X_i$ |
| **MVUE（$\theta$）** | 无初等闭式（依赖 $\psi^{-1}$）；⭐ 关键是完备充分统计量为 $\sum\ln X_i$，任何 MVUE 都是它的函数 |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{(\theta-1)}_{p(\theta)}\underbrace{\ln x}_{K(x)}+\underbrace{-x/\beta_0}_{H(x)}+\underbrace{-\ln\Gamma(\theta)-\theta\ln\beta_0}_{q(\theta)}\Big\},\quad S=(0,\infty).$$
准确写法（期末总结 13.3 表）：$K(x)=\ln x$，$p(\theta)=\theta-1$，$H(x)=-x/\beta_0$，$q(\theta)=-\ln\Gamma(\theta)-\theta\ln\beta_0$（此时 $p$ 非平凡、连续，正则性成立；$E[K]$、$\text{Var}(K)$ 用此写法计算）。

> ⚠️ 形状参数未知的 Gamma **无初等 MLE / Fisher 闭式**，期末总结也只列了分解形式。本篇忠实记录这一点，不臆造闭式。

按期末总结写法（$p=\theta-1$，$K=\ln x$，$q=-\ln\Gamma(\theta)-\theta\ln\beta_0$）：
- $p'=1$，$p''=0$；$q'=-\psi(\theta)-\ln\beta_0$，$q''=-\psi'(\theta)$。
- $E[K(X)]=E[\ln X]=-\dfrac{q'}{p'}=\psi(\theta)+\ln\beta_0$ ✓（与已知 $E[\ln X]=\psi(\theta)+\ln\beta_0$ 一致）
- $\text{Var}(K(X))=\text{Var}(\ln X)=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{0-(-\psi'(\theta))\cdot1}{1}=\psi'(\theta)$ ✓（trigamma）

### 12. Beta 分布 $\text{Beta}(\theta,1)$，$\theta>0$

p.d.f. $f(x;\theta)=\theta x^{\theta-1}$，$0<x<1$。$E[X]=\dfrac{\theta}{\theta+1}$，$\text{Var}(X)=\dfrac{\theta}{(\theta+1)^2(\theta+2)}$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta=-\dfrac{n}{\sum\ln X_i}$ |
| **Fisher 信息量** | $I(\theta)=\dfrac1{\theta^2}$ |
| **充分统计量** | $T=\sum\ln X_i$（或等价 $\prod X_i$），**CSS ✓** |
| **最小充分** | $\sum\ln X_i$ |
| **MVUE（$\theta$）** | 纠偏：$\tilde\theta=\dfrac{n-1}{n}\hat\theta=-\dfrac{n-1}{\sum\ln X_i}$（因 $-\sum\ln X_i\sim\Gamma(n,\theta)$，$E[1/\sum\ln X_i]=\frac{\theta}{n-1}$）。⚠️ **非有效**：$\text{eff}(\tilde\theta)=\frac{n-2}{n}\to1$（渐近有效，期末总结 9.4） |

**正则指数族分解**：
$$f(x;\theta)=\exp\Big\{\underbrace{\theta-1}_{p(\theta)}\underbrace{\ln x}_{K(x)}+\underbrace{0}_{H(x)}+\underbrace{\ln\theta}_{q(\theta)}\Big\},\quad S=(0,1).$$

> ⚠️ 严格正则指数族要求 $p$ 非平凡——这里 $p(\theta)=\theta-1$ 含常数 $-1$，可等价把 $-1$ 吸收进 $H(x)=-\ln x$、$p(\theta)=\theta$；两种写法等价，期末总结 13.3 表用前者。下用 $p=\theta-1$ 计算。

- $p'=1$，$p''=0$；$q'=\frac1\theta$，$q''=-\frac1{\theta^2}$。
- $E[K(X)]=E[\ln X]=-\dfrac{q'}{p'}=-\dfrac{1/\theta}{1}=-\dfrac1\theta$ ✓（$\text{Beta}(\theta,1)$ 下 $E[\ln X]=-\frac1\theta$，正确）
- $\text{Var}(K(X))=\text{Var}(\ln X)=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{0-(-1/\theta^2)\cdot1}{1}=\dfrac1{\theta^2}$ ✓

> 🎯 Beta$(\theta,1)$ 是考"纠偏后非有效但渐近有效"的典型（期末总结 9.4、10.6 三检验）。

### 13. Weibull 分布（$k_0$ 已知），$\theta>0$

p.d.f. $f(x;\theta)=\dfrac{k_0}{\theta^{k_0}}x^{k_0-1}\exp\!\big(-x^{k_0}/\theta^{k_0}\big)$，$x>0$（期末总结 HW7 P4）。

| 项目 | 内容 |
|------|------|
| **变换化归** | 令 $Y_i=X_i^{k_0}$，则 $Y_i\sim\text{Exp}(1/\theta^{k_0})=\Gamma(1,\theta^{k_0})$。故一切化归为 mean-参数化指数分布，参数为 $\eta=\theta^{k_0}$。 |
| **MLE** | $\widehat{\theta^{k_0}}=\dfrac{\sum X_i^{k_0}}{n}$（即 $\hat\eta=\bar Y$） |
| **Fisher 信息量** | 对 $\eta=\theta^{k_0}$：$I(\eta)=\dfrac1{\eta^2}$；对 $\theta$ 由不变性换算 |
| **充分统计量** | $T=\sum X_i^{k_0}\,(=\sum Y_i)$，**CSS ✓**（经 $Y_i$ 化归指数族） |
| **最小充分** | $\sum X_i^{k_0}$ |
| **MVUE（$\theta^{k_0}$）** | $\dfrac{\sum X_i^{k_0}}{n}$（化归 mean-Exp，无偏有效） |

**正则指数族分解**（对 $Y=X^{k_0}$，即 $\text{Exp}(1/\eta)$）：
$$f_Y(y;\eta)=\exp\Big\{\underbrace{-1/\eta}_{p(\eta)}\underbrace{y}_{K(y)}+\underbrace{0}_{H(y)}+\underbrace{-\ln\eta}_{q(\eta)}\Big\},\quad S=(0,\infty),\ \eta=\theta^{k_0}.$$
$E[K(Y)]=\eta=\theta^{k_0}$，$\text{Var}(K(Y))=\eta^2=\theta^{2k_0}$（同第 9 条 mean-Exp 结论）。

> 💡 Weibull 本身不是标准指数族，但经 $Y=X^{k_0}$ 单调变换后落到指数族——这是"化归法"的典型。

### 14. 瑞利分布 $f(x;\sigma)=\dfrac{x}{\sigma^2}e^{-x^2/(2\sigma^2)}$，$x>0$，$\sigma>0$

| 项目 | 内容 |
|------|------|
| **变换化归** | 令 $Y_i=X_i^2$，则 $Y_i\sim\text{Exp}(1/(2\sigma^2))=\Gamma(1,2\sigma^2)$。参数 $\eta=2\sigma^2$。 |
| **MLE** | $\hat\sigma^2=\dfrac1{2n}\sum X_i^2$（期末总结 Ass5 P8） |
| **Fisher 信息量** | 对 $\eta=2\sigma^2$：$I(\eta)=1/\eta^2$ |
| **充分统计量** | $T=\sum X_i^2\,(=\sum Y_i)\sim\Gamma(n,2\sigma^2)$，**CSS ✓**（期末总结 HW7 P1） |
| **最小充分** | $\sum X_i^2$ |
| **LRT 检验统计量化归** | $W=\dfrac1{\sigma_0^2}\sum X_i^2\sim\chi^2(2n)$（$H_0$ 下，期末总结 Ass5 P8） |

**正则指数族分解**（对 $Y=X^2\sim\text{Exp}(1/\eta)$，$\eta=2\sigma^2$）：
$$f_Y(y;\eta)=\exp\Big\{\underbrace{-1/\eta}_{p(\eta)}\underbrace{y}_{K(y)}+\underbrace{0}_{H(y)}+\underbrace{-\ln\eta}_{q(\eta)}\Big\},\quad S=(0,\infty).$$
$E[K(Y)]=\eta=2\sigma^2$，$\text{Var}(K(Y))=\eta^2=4\sigma^4$。

> ⚠️ 瑞利与 Weibull 同属"平方/幂变换落到指数族"一族；瑞利是 Weibull $k_0=2$、$\theta=\sqrt2\,\sigma$ 的特例。

### 15. 拉普拉斯 location $f(x;\theta)=\dfrac12 e^{-|x-\theta|}$，$\theta\in\mathbb R$

| **类型** | **Location family，非正则指数族**（$|x-\theta|$ 不可写成 $p(\theta)K(x)+H(x)$ 的可加分离形式） |

### 20. 正态 $N(\theta_1,\theta_2)$（$\mu,\sigma^2$ 均未知）

p.d.f. $f(x;\boldsymbol\theta)=\dfrac1{\sqrt{2\pi\theta_2}}e^{-(x-\theta_1)^2/(2\theta_2)}$，$\theta_2>0$。属 location-scale family。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat\theta_1=\bar X$，$\hat\theta_2=\dfrac1n\sum(X_i-\bar X)^2$ |
| **Fisher 信息矩阵** | $I(\boldsymbol\theta)=\begin{pmatrix}1/\theta_2&0\\0&1/(2\theta_2^2)\end{pmatrix}$（期末总结 11.2） |
| **充分统计量** | $(\sum X_i,\sum X_i^2)$ 或等价 $(\bar X,S^2)$，**联合 CSS ✓** |
| **最小充分** | $(\sum X_i,\sum X_i^2)$ |
| **MVUE（$\mu$）** | $\bar X$ |
| **MVUE（$\sigma^2$）** | $S^2=\dfrac1{n-1}\sum(X_i-\bar X)^2$（$\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$，无偏） |
| **方差未知时 $\mu$ 检验** | LRT $\Rightarrow$ t 检验，$T=\frac{\bar X-\mu_0}{S/\sqrt n}\sim t(n-1)$（期末总结 11.5） |
| **多组均值检验** | LRT $\Rightarrow$ ANOVA F 检验（期末总结 11.6） |

**正则指数族分解**（双参数）：
$$f(x;\boldsymbol\theta)=\exp\Big\{\underbrace{\theta_1/\theta_2}_{p_1}\underbrace{x}_{K_1}+\underbrace{-1/(2\theta_2)}_{p_2}\underbrace{x^2}_{K_2}+\underbrace{-\tfrac12\ln(2\pi\theta_2)-\theta_1^2/(2\theta_2)}_{q(\boldsymbol\theta)}\Big\},\quad S=\mathbb R.$$
即 $K_1(x)=x$，$K_2(x)=x^2$；完备充分统计量 $(\sum X_i,\sum X_i^2)$。

> 💡 Basu 定理：$T=(\sum X_i,\sum X_i^2)$ 完备充分时，从属统计量（如 $X_1/X_2$ 在 $\mu=0$ 已知时）与之独立。

### 21. 拉普拉斯 $f(x;a,b)=\dfrac1{2b}e^{-|x-a|/b}$（$a$ 已知，估 $b$），$b>0$

| 项目 | 内容 |
|------|------|
| **类型** | $a$ 已知时关于 $b$ **是正则指数族**（期末总结 HW7 P1(2)） |
| **MLE** | $\hat b=\dfrac1n\sum|X_i-a|$ |
| **充分统计量** | $T=\sum|X_i-a|$，**CSS ✓** |
| **最小充分** | $\sum|X_i-a|$ |

**正则指数族分解**（$a$ 已知）：
$$f(x;b)=\exp\Big\{\underbrace{-1/b}_{p(b)}\underbrace{|x-a|}_{K(x)}+\underbrace{0}_{H(x)}+\underbrace{-\ln(2b)}_{q(b)}\Big\},\quad S=\mathbb R.$$
- $p'=\frac1{b^2}$，$p''=-\frac2{b^3}$；$q'=-\frac1b$，$q''=\frac1{b^2}$。
- $E[K(X)]=E[|X-a|]=-\dfrac{q'}{p'}=-\dfrac{-1/b}{1/b^2}=b$ ✓（$|X-a|\sim\text{Exp}(1/b)$，均值 $b$）
- $\text{Var}(K(X))=\dfrac{p''q'-q''p'}{(p')^3}=\dfrac{(-2/b^3)(-1/b)-(1/b^2)(1/b^2)}{1/b^6}=\dfrac{2/b^4-1/b^4}{1/b^6}=b^2$ ✓

> 💡 $a$ 已知时 $|X-a|\sim\text{Exp}(1/b)$，化归为 mean-Exp（第 9 条），一切结论照搬。

### 23. 逆高斯分布 $f(x;\mu,\lambda)=\sqrt{\dfrac{\lambda}{2\pi x^3}}\exp\!\Big(-\dfrac{\lambda(x-\mu)^2}{2\mu^2 x}\Big)$，$x>0$

|------|------|
| **MLE** | $\hat\mu=\bar X$，$\hat\lambda=\dfrac{n\bar X^2}{\sum\frac{(X_i-\bar X)^2}{X_i}}$（期末总结 Ass6 P1） |
| **充分统计量** | $(T_1,T_2)=\Big(\sum X_i,\sum\dfrac1{X_i}\Big)$，**联合 CSS ✓**（期末总结 HW7 P8） |
| **最小充分** | $(\sum X_i,\sum 1/X_i)$ |

**正则指数族分解**（双参数，期末总结 HW7 P8）：
$$f(x;\theta_1,\theta_2)=\exp\Big\{\underbrace{-\tfrac{\theta_1}{2\theta_2^2}}_{p_1}\underbrace{x}_{K_1}+\underbrace{-\tfrac{\theta_1}{2}}_{p_2}\underbrace{\tfrac1x}_{K_2}+\underbrace{\tfrac{\theta_1}{\theta_2}+\tfrac12\ln\tfrac{\theta_1}{2\pi x^3}}_{\text{含 }q\text{ 与 }H}\Big\}.$$
准确拆分：$K_1(x)=x,\ p_1=-\frac{\theta_1}{2\theta_2^2}$；$K_2(x)=\frac1x,\ p_2=-\frac{\theta_1}{2}$；$H(x)=-\frac32\ln x-\frac12\ln(2\pi)$；$q(\boldsymbol\theta)=\frac{\theta_1}{\theta_2}+\frac12\ln\theta_1$。$S=(0,\infty)$。

> ⭐ 完备充分统计量 $\big(\sum X_i,\sum 1/X_i\big)$ 是双参数指数族的典型，与正态 $(\sum X_i,\sum X_i^2)$ 对照。

### 24. 多项分布 $\text{Multinomial}(n;p_1,\ldots,p_k)$，$\sum p_i=1$

p.m.f. $f(\mathbf x;\mathbf p)=\dfrac{n!}{\prod x_i!}\prod_{i=1}^k p_i^{x_i}$，$\sum x_i=n$。参数 $(p_1,\ldots,p_{k-1})$，$p_k=1-\sum_{i=1}^{k-1}p_i$。

| 项目 | 内容 |
|------|------|
| **MLE** | $\hat p_i=X_i/n$，$i=1,\ldots,k$（期末总结 Ass6 P2） |
| **Fisher 信息矩阵** | $I(\mathbf p)=n\,\text{diag}\!\Big(\frac1{p_1},\ldots,\frac1{p_{k-1}}\Big)+\frac n{p_k}\mathbf1\mathbf1^\top$，逆 $[I]^{-1}=\frac1n\big(\text{diag}(\mathbf p)-\mathbf p\mathbf p^\top\big)$（期末总结 11.2） |
| **充分统计量** | $(X_1,\ldots,X_{k-1})$（或等价 $(X_1,\ldots,X_k)$，受 $\sum=n$ 约束），**联合 CSS ✓** |
| **最小充分** | $(X_1,\ldots,X_k)$ |
| **LRT（$H_0$：均匀 $p_i=1/k$）** | $\Lambda=\prod_{i=1}^k\big(\frac{n}{3X_i}\big)^{X_i}$（$k=3$），$-2\ln\Lambda\xrightarrow d\chi^2(k-1)$（期末总结 11.7） |
| **LRT（$H_0:p_1-p_2=0.03$）** | Lagrange 乘子求约束 MLE，自由度 $=1$（期末总结 11.7(b)） |

**正则指数族分解**（多参数，参数 $\mathbf p=(p_1,\ldots,p_{k-1})$）：
$$f(\mathbf x;\mathbf p)=\exp\Big\{\sum_{i=1}^{k-1}\underbrace{\ln\frac{p_i}{p_k}}_{p_i(\mathbf p)}\underbrace{x_i}_{K_i(\mathbf x)}+\underbrace{\ln\frac{n!}{\prod x_i!}}_{H(\mathbf x)}+\underbrace{n\ln p_k}_{q(\mathbf p)}\Big\},\quad S=\{\mathbf x:\sum x_i=n,\ x_i\ge0\}.$$

> 💡 $k$ 个 $K_i=x_i$ 但参数 $k-1$ 个（因 $\sum p_i=1$ 约束）；完备充分统计量取 $(X_1,\ldots,X_{k-1})$，$X_k$ 由 $\sum=n$ 确定。

## 五、坑（易错点）

1. **指数分布参数化** ⚠️：rate 版 $f=\theta e^{-\theta x}$（$E=1/\theta$）的 MLE $1/\bar X$ **有偏**；mean 版 $f=\frac1\theta e^{-x/\theta}$（$E=\theta$）的 MLE $\bar X$ **无偏有效**。期末总结 Ass5 P2 专门提示此勘误。算 MVUE 前先确认是哪种参数化。

2. **Gamma 的两种未知情形** ⚠️：$\Gamma(\alpha_0,\beta)$（形状已知估尺度）有初等 MLE/MVUE 且有效；$\Gamma(\theta,\beta_0)$（尺度已知估形状）**无初等闭式**，Fisher 信息量是 trigamma $\psi'(\theta)$。别混淆。

3. **正则指数族 $p(\theta)$ 含常数** ⚠️：如 $\text{Beta}(\theta,1)$ 的 $p=\theta-1$、负二项的 $p=\theta$（vs 几何的 $p=\ln(1-\theta)$）。写 $E[K]=-\frac{q'}{p'}$ 时必须与所选 $p,q$ 写法一致；常数可任归 $H$ 或 $p$，但一旦选定就要配套算。本篇逐条核对了所选写法下的 $E[K]$、$\text{Var}(K)$。

4. **$U[0,\theta]$ 是"非正则但有 CSS"** ⚠️：支撑依赖参数 → 非正则指数族 → 正则条件 R0-R4 不成立 → **RCB 不适用**；但 $X_{(n)}$ 仍完备充分（经求导法另证），MVUE $\frac{n+1}{n}X_{(n)}$ 走 Lehmann-Scheffe，其方差不必达任何 C-R 下界。别因"非正则"就以为没有 MVUE。

5. **$U[\theta-1,\theta+1]$ 是"最小充分但不完备"** ⚠️：$(X_{(1)},X_{(n)})$ 最小充分但**不完备**（有非零均值零的 $u$）。证明"最小充分 $\not\Rightarrow$ 完备"的反例。MSS 维数 $=2\ne$ 参数维数 $=1$。

6. **拉普拉斯 location 非指数族** ⚠️：$|x-\theta|$ 不可加分离，故非正则指数族；Fisher 信息量 $I(\theta)=1$ 是**常数**（location family 通性）；MLE 是中位数 $Q_2$（不是均值！）；无低维充分统计量。Score 检验用 $\sum\text{sgn}(X_i-\theta_0)$。

7. **形状参数未知的 Gamma / 逆高斯 / Multinomial 的"完备充分"是多维向量** ⚠️：$\Gamma(\theta,\beta_0)$ 的 CSS 是 $\sum\ln X_i$（一维但非 $X$）；逆高斯是 $(\sum X_i,\sum 1/X_i)$；正态双参是 $(\sum X_i,\sum X_i^2)$；Multinomial 是 $(X_1,\ldots,X_{k-1})$。别一律写 $\sum X_i$。

8. **Weibull / 瑞利要先变换化归** ⚠️：它们本身不是标准指数族，但 $Y=X^{k_0}$（Weibull）或 $Y=X^2$（瑞利）后落到 $\text{Exp}$，CSS 变成 $\sum X_i^{k_0}$ 或 $\sum X_i^2$。直接对原 $X$ 套指数族公式会错。

9. **Binomial$(m,\theta)$ 抽样 vs Bernoulli 抽样** ⚠️：$X_i\sim\text{Bin}(m,\theta)$ 时 $\sum X_i\sim\text{Bin}(mn,\theta)$，$I(\theta)=m/[\theta(1-\theta)]$，MLE $\bar X/m$。期末总结 HW7 P7 是 $m=2$ 的例子，别当成 Bernoulli 算。

10. **"有效 $\Rightarrow$ MVUE"但"MVUE $\not\Rightarrow$ 有效"** ⚠️：有效估计量（达 RCB）必是 MVUE；但 MVUE 未必有效（如 $U[0,\theta]$ 的 $\frac{n+1}{n}X_{(n)}$ 根本不受 RCB 约束，$\text{Beta}(\theta,1)$ 纠偏后渐近有效但有限样本非有效）。
