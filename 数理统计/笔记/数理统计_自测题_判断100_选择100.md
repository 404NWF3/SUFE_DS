## 一、判断题（共 100 题，每题 2 分）

### A. 抽样分布与学生定理 / 基础回顾

1. 若 $X_1,\ldots,X_n \stackrel{iid}{\sim} N(0,1)$，则 $\sum_{i=1}^n X_i^2 \sim \chi^2(n)$，且 $E\left(\sum X_i^2\right)=n$，$\text{Var}\left(\sum X_i^2\right)=2n$。(   T   )
   > 解析：$\chi^2(n)=\Gamma(n/2,2)$，均值 $n$、方差 $2n$，标准结论。

2. 设 $X\sim N(0,1)$，$Y\sim\chi^2(n)$ 独立，则 $T=\dfrac{X}{\sqrt{Y/n}}\sim t(n)$；当 $n=1$ 时 $t(1)$ 就是标准柯西分布，期望不存在。(   T   )
   > 解析：$n=1$ 时 $t(1)$ 即柯西分布，$E(T)$ 不存在，故 "$E(T)=0$ 对一切 $n$ 成立" 是错的（$n=1$ 例外）。

3. 设 $X\sim\chi^2(n_1)$，$Y\sim\chi^2(n_2)$ 独立，则 $F=\dfrac{X/n_1}{Y/n_2}\sim F(n_1,n_2)$，且 $\dfrac{1}{F}\sim F(n_2,n_1)$。(   T   )

4. $F$ 分布分位数恒等式 $F_{1-\alpha}(n_1,n_2)=\dfrac{1}{F_{\alpha}(n_2,n_1)}$ 成立。(   T   )

5. 学生定理保证：对正态样本，$\bar X$ 与 $S^2$ 不仅各自有良好分布，而且**互相独立**。(   T   )

6. 设 $X_1,\ldots,X_n\stackrel{iid}{\sim}N(\mu,\sigma^2)$，则 $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n)$。(   F   )
   > 解析：自由度应为 $n-1$，不是 $n$。

7. 设 $X_1,\ldots,X_n\stackrel{iid}{\sim}N(\mu,\sigma^2)$，则 $\dfrac{\bar X-\mu}{S/\sqrt n}\sim N(0,1)$。(   F   )
   > 解析：应为 $t(n-1)$；$S$ 随机而非已知常数。

8. $\text{Exp}(\theta)$（rate 参数，p.d.f. $\theta e^{-\theta x}$）与 $\Gamma(1,1/\theta)$ 是同一分布。(   T   )

9. $\chi^2(n)=\Gamma(n/2, 2)$，既是 $\chi^2$ 也是 Gamma。(   T   )

10. 若 $X_1,\ldots,X_n\stackrel{iid}{\sim}\text{Exp}(\theta)$（rate $\theta$），则 $\sum X_i\sim\Gamma(n,1/\theta)$，期望 $n/\theta$，方差 $n/\theta^2$。(   T   )

11. 正态样本方差 $S^2=\dfrac{1}{n}\sum(X_i-\bar X)^2$ 是 $\sigma^2$ 的无偏估计。(   F   )
    > 解析：分母 $n$ 时有偏；**无偏**定义为分母 $n-1$。样卷口径此处要分清。

12. 对任何总体，$\bar X$ 都是 $E[X]$ 的无偏估计；但 $\bar X$ 不一定是有效估计。(   T   )
    > 解析：无偏与有效是两件事，仅在特定分布（如 Bernoulli、Poisson、正态均值已知方差）下 $\bar X$ 才达到 RCB。

13. 若 $X\sim t(n)$，则 $X^2\sim F(1,n)$。(   T   )

14. $z_\alpha$ 表示标准正态的上 $\alpha$ 分位数，即 $P(Z>z_\alpha)=\alpha$。(   T   )

15. 区间估计 $\bar X\pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt n}$ 适用于 $\sigma$ 未知且正态总体的 $\mu$ 区间估计。(   T   )

### B. Fisher 信息量 / Rao-Cramer 下界 / 有效性

16. Fisher 信息量 $I(\theta)$ 一定非负。(   T   )
    > 解析：$I(\theta)=\text{Var}\!\left(\dfrac{\partial\ln f}{\partial\theta}\right)\ge0$。

17. 对 $k(\theta)$ 的任意无偏估计 $Y$，$\text{Var}(Y)\ge\dfrac{[k'(\theta)]^2}{nI(\theta)}$，下界只对**无偏**估计成立。(   T   )
    > 解析：有偏估计不受此下界约束（RCB 是无偏估计的方差下界）。样卷考过"任何估计量方差不会低于 RCB" → 错。

18. 若 $k(\theta)=\theta$，则 RCB 简化为 $\dfrac{1}{nI(\theta)}$。(   T   )

19. 对 Location Family $f(x;\theta)=h(x-\theta)$，Fisher 信息量 $I(\theta)$ 不依赖于 $\theta$（为常数）。(   T   )
    > 解析：位移模式使导数关于 $\theta$ 对称平移，信息量与 $\theta$ 无关。

20. 拉普拉斯分布 $f(x;\theta)=\tfrac12 e^{-|x-\theta|}$ 的 $I(\theta)$ 等于 $1$（常数）。(   T   )

21. $\text{Bernoulli}(\theta)$ 的 Fisher 信息量为 $\dfrac{1}{\theta(1-\theta)}$。(   T   )

22. $\text{Po}(\theta)$ 的 Fisher 信息量为 $\dfrac{1}{\theta^2}$。(   F   )
    > 解析：$\text{Po}(\theta)$ 的 $I(\theta)=1/\theta$，不是 $1/\theta^2$；后者是 $\text{Exp}(\theta)$。

23. $N(\theta,\sigma_0^2)$（$\sigma_0^2$ 已知）的 $I(\theta)=1/\sigma_0^2$。(   T   )

24. $N(\mu_0,\theta)$（$\theta$ 为方差）的 $I(\theta)=\dfrac{1}{2\theta^2}$。(   T   )

25. $\text{Exp}(\theta)$ rate 参数下 $I(\theta)=\dfrac{1}{\theta^2}$；若改用均值参数化 $f(x;\theta)=\tfrac1\theta e^{-x/\theta}$，则信息量变为 $\dfrac{1}{\theta^2}$ 的同样形式。(   T   )
    > 解析：两种参数化下信息量数值形式同为 $1/\theta^2$，但量纲与"哪个 $\theta$"含义不同；务必分清是 rate 还是 mean。

26. 参数化方式不同，同一分布族的 Fisher 信息量可能不同；RCB 用到的 $I(\theta)$ 必须与估计对象一致。(   T   )

27. 有效估计量的有效性 $\text{eff}(Y)=\dfrac{1/[nI(\theta)]}{\text{Var}(Y)}$ 一定落在 $[0,1]$。(   T   )

28. 有效估计量一定是 MVUE，但 MVUE 不一定有效（未必达到 RCB）。(   T   )
    > 解析：样卷 Spring25 第 1 题原题。MVUE 在所有无偏估计中方差最小，但该最小值未必等于 RCB。

29. 若某无偏估计达到 RCB，则它一定是唯一 MVUE。(   T   )

30. $\text{Beta}(\theta,1)$ 纠偏后的 $\tilde\theta=\dfrac{n-1}{n}\hat\theta$ 是有效估计量。(   F   )
    > 解析：$\tilde\theta$ 渐近有效 $\text{eff}\to 1$，但**有限样本下不达 RCB**，不是有效估计。

31. 对 $\Gamma(\alpha_0,\beta)$（$\alpha_0$ 已知，估 $\beta$），$\hat\beta=\bar X/\alpha_0$ 达到 RCB，是有效估计。(   T   )

32. Rao-Cramer 下界的证明中，关键是利用 Cauchy-Schwarz 不等式估计 $\text{Cov}\!\left(Y,\sum\dfrac{\partial\ln f}{\partial\theta}\right)$。(   T   )

33. 正则条件下，得分函数 $S(\theta)=\dfrac{\partial\ln f}{\partial\theta}$ 的期望恒为 $0$。(   T   )

34. 二阶导恒等式 $I(\theta)=-E\!\left[\dfrac{\partial^2\ln f}{\partial\theta^2}\right]$ 要求正则条件（积分与求导可交换）才成立。(   T   )

35. Fisher 信息量可加：对 iid 样本，总样本信息量 $nI_1(\theta)$；得分向量方差即 $nI(\theta)$。(   T   )

### C. MLE / 不变性 / 相合性

36. MLE 的不变性定理：若 $\hat\theta$ 为 $\theta$ 的 MLE，$\eta=g(\theta)$，则 $\hat\eta=g(\hat\theta)$ 为 $\eta$ 的 MLE。(   T   )

37. MLE 在正则条件下相合：$\hat\theta\xrightarrow{P}\theta_0$。(   T   )

38. MLE 一定是无偏估计。(   F   )
    > 解析：$\text{Exp}(\theta)$ 的 $\hat\theta=1/\bar X$ 有偏；$\text{Beta}(\theta,1)$ 的 $\hat\theta=-n/\sum\ln X_i$ 也需纠偏。

39. MLE 一定是充分统计量的函数（若 MLE 唯一存在）。(   T   )

40. 拉普拉斯 location family 的 MLE 是样本均值 $\bar X$。(   F   )
    > 解析：是样本中位数 $Q_2$，不是均值。

41. $\text{Exp}(\theta)$ rate 参数下 $\hat\theta=1/\bar X$；它是有偏的，$E[\hat\theta]\ne\theta$。(   T   )

42. $U[0,\theta]$ 的 MLE 为 $\hat\theta=X_{(n)}$，且它本身是充分统计量。(   T   )

43. $\text{Beta}(\theta,1)$ 的 MLE 为 $\hat\theta=-n/\sum\ln X_i$。(   T   )

44. Logistic location family 与拉普拉斯 location family 的 MLE 都有简单显示解 $\hat\theta=Q_2$。(   F   )
    > 解析：Logistic 的 MLE 无显示解，需数值方法；拉普拉斯才是 $Q_2$。

45. MLE 的渐近正态性：$\sqrt{nI_1(\theta_0)}(\hat\theta-\theta_0)\xrightarrow{d}N(0,1)$。(   T   )

46. $N(\mu_0,\theta)$（已知均值，估方差）的 MLE $\hat\theta=\dfrac1n\sum(X_i-\mu_0)^2$ 是 $\theta$ 的无偏估计。(   T   )
    > 解析：$\sum(X_i-\mu_0)^2/\theta\sim\chi^2(n)$，$E[\hat\theta]=\theta$，确实无偏。

47. 若参数空间被限制为 $\theta\in[0,1/3]$，Bernoulli 的 MLE 为 $\hat\theta=\min\{\bar X,1/3\}$。(   T   )

48. MLE 不变性意味着复合参数（如 $e^{-2\theta}$）的 MLE 等于把 $\hat\theta$ 直接代入。(   T   )
    > 解析：例 $g(\theta)=e^{-2\theta}$ 的 MLE 即 $e^{-2\hat\theta}$。

49. $U[0,\theta]$ 的均值参数化 $g(\theta)=\theta/2$ 的 MLE 为 $\hat\theta/2=X_{(n)}/2$。(   T   )

50. 多参数情形下 MLE 同样满足不变性：$\widehat{g(\boldsymbol\theta)}=g(\hat{\boldsymbol\theta})$。(   T   )

### D. 似然比检验 / Wald / Score

51. 似然比 $\Lambda=\dfrac{L(\theta_0)}{L(\hat\theta)}\le1$ 恒成立，因为 MLE 最大化似然函数。(   T   )

52. 在正则条件下，$H_0:\theta=\theta_0$ 成立时 $-2\ln\Lambda\xrightarrow{d}\chi^2(1)$。(   T   )

53. $-2\ln\Lambda$ 渐近分布的证明中，关键用到 MLE 一阶条件 $l'(\hat\theta)=0$ 与 Taylor 展开。(   T   )

54. Wald 型检验统计量 $\chi^2_W=nI(\hat\theta)(\hat\theta-\theta_0)^2$ 在 $H_0$ 下渐近 $\chi^2(1)$。(   T   )

55. Score 检验统计量 $\chi^2_R=\dfrac{[l'(\theta_0)]^2}{nI(\theta_0)}$，它**无需**求无约束 MLE 即可计算。(   T   )
    > 解析：Score 只需在 $\theta_0$ 处求导；Wald 需无约束 MLE；LRT 需同时拟合约束与无约束两个模型。

56. 三个检验（LRT/Wald/Score）在 $H_0$ 下大样本渐近等价，自由度都等于约束个数。(   T   )

57. 单参数检验中，Wald 检验的自由度为 1。(   T   )

58. 对正态 $N(\theta,\sigma_0^2)$ 的 LRT，拒绝域 $\Lambda\le c$ 等价于 $|\bar X-\theta_0|\ge c'\sigma_0/\sqrt n$，即 Z 检验。(   T   )

59. 对 $\text{Exp}(\theta)$ 的 LRT，$2n\theta_0\bar X\sim\chi^2(2n)$ 在 $H_0$ 下成立。(   T   )

60. 多参数 Wald 检验 $\chi^2_W=n(\hat{\boldsymbol\theta}-\boldsymbol\theta_0)^T I(\hat{\boldsymbol\theta})(\hat{\boldsymbol\theta}-\boldsymbol\theta_0)$，自由度为参数维数 $p$（当 $H_0$ 完全指定 $\boldsymbol\theta_0$ 时）。(   T   )

61. 多参数 Score 检验的自由度等于参数维数 $p$（而与 $H_0$ 施加的约束个数 $r$ 无关）。(   F   )
    > 解析：三检验自由度统一为约束个数 $r$。当 $H_0$ 完全指定整个 $p$ 维向量时 $r=p$；只约束部分参数时 $r<p$，自由度为 $r$ 而非 $p$。故"与 $r$ 无关"为错。

62. 卡方检验统一"右尾拒绝"：统计量越大越偏离 $H_0$。(   T   )

63. $-2\ln\Lambda$ 退化地等于 Wald 统计量，二者恒等。(   F   )
    > 解析：仅大样本渐近等价，有限样本一般不相等。

64. 多项分布 $(X_1,\ldots,X_k)\sim\text{Multinomial}(n;p_1,\ldots,p_k)$ 的 Fisher 信息阵逆为 $\dfrac1n(\text{diag}(p_1,\ldots,p_{k-1})-\boldsymbol p\boldsymbol p^T)$。(   T   )

65. 正态 $N(\theta_1,\theta_2)$ 的 Fisher 信息阵为对角阵 $\text{diag}(1/\theta_2,1/(2\theta_2^2))$。(   T   )
    > 解析：均值与方差参数信息正交，故非对角元为 0。

66. 单因素方差分析 LRT 等价于 F 检验，$F=\dfrac{SSB/(k-1)}{SSW/(n-k)}\sim F(k-1,n-k)$（$H_0$ 下）。(   T   )

67. 正态方差未知时 LRT 推导出的检验是 t 检验，统计量 $\dfrac{\bar X-\theta_{10}}{S/\sqrt n}\sim t(n-1)$。(   T   )

68. 多参数 Rao-Cramer 下界：$\text{Cov}(\mathbf Y)\ge\dfrac1n[I(\boldsymbol\theta)]^{-1}$（半正定序）。(   T   )

69. 多参数 LRT 的 $-2\ln\Lambda\xrightarrow{d}\chi^2(r)$，其中 $r$ 为 $H_0$ 施加的独立约束个数。(   T   )

70. Wald 检验只需在 $\hat{\boldsymbol\theta}$（MLE）处估计信息阵，无需在 $\boldsymbol\theta_0$ 处求导。(   T   )

### E. 充分统计量 / Neyman 分解 / Rao-Blackwell

71. 充分统计量 $Y$ 的定义：给定 $Y=y$ 时样本的条件分布不依赖于 $\theta$。(   T   )

72. 充分统计量唯一存在。(   F   )
    > 解析：样卷 Spring26 原题。充分统计量不唯一；其一一对应函数也是充分统计量（如 $\sum X_i$ 与 $\bar X$）。

73. 最小充分统计量唯一存在。(   F   )
    > 解析：样卷 Spring24 选项曾以此考查。最小充分统计量在"等价类"意义下唯一，但作为随机变量其形式不唯一（一一对应变形仍是最小充分）。

74. 若 $Y_1$ 充分，$Y_2=g(Y_1)$ 且 $g$ 为一一对应，则 $Y_2$ 也充分。(   T   )

75. 若 $Y_1,Y_2$ 均为充分统计量，则 $Y_1+Y_2$ 也一定是充分统计量。(   F   )
    > 解析：两充分统计量之和未必充分；样卷 Spring24 考过此陷阱。

76. Neyman 分解定理：$f(x_1,\ldots,x_n;\theta)=g(u(x);\theta)h(x)$ 是 $Y=u(x)$ 充分的充要条件。(   T   )

77. MLE 唯一存在时，它是充分统计量的函数。(   T   )

78. 若 MLE 自身即为充分统计量，则它必为最小充分统计量。(   T   )

79. Rao-Blackwell 定理要求 $T$ 是充分统计量，否则 $E[Y|T]$ 可能依赖于 $\theta$、不是统计量。(   T   )

80. Rao-Blackwell 化后 $\varphi(T)=E[Y|T]$ 的方差不增，且保持无偏性。(   T   )

81. 对 $X_1,X_2\sim N(\theta,1)$，$T=X_1+2X_2$ 不是充分统计量，$E[X_1|T]$ 依赖于 $\theta$。(   T   )
    > 解析：经典反例：$T$ 不充分时条件期望非统计量。

82. 充分统计量"压缩了数据而不损失关于 $\theta$ 的信息"。(   T   )

83. $U[0,\theta]$ 的充分统计量是 $X_{(n)}=\max X_i$。(   T   )

84. $N(\theta,\sigma_0^2)$（$\sigma_0$ 已知）的充分统计量为 $\sum X_i$ 或 $\bar X$。(   T   )

85. $N(\theta_1,\theta_2)$（双参数未知）的联合充分统计量为 $(\sum X_i,\sum X_i^2)$。(   T   )

86. $\text{Beta}(\theta,1)$ 的充分统计量为 $\sum\ln X_i$（或等价 $\prod X_i$）。(   T   )

### F. 完备性 / 正则指数族 / Lehmann-Scheffé

87. 完备性的定义：若 $E_\theta[u(Z)]=0$ 对**每个** $\theta$ 成立，则 $u(Z)\equiv0$ a.s.。(   T   )

88. 完备性要求 $E_\theta[u(Z)]=0$ 对**某个** $\theta$ 成立即推出 $u(Z)\equiv0$。(   F   )
    > 解析：样卷 Spring24 原题。必须对**所有** $\theta\in\Omega$ 成立才推得出；只对某个 $\theta$ 成立推不出。完备族的反例如常见。

89. $\text{Exp}(1/\theta)$ 的完备性用 Laplace 变换唯一性论证。(   T   )

90. $\text{Po}(\theta)$ 的完备性用幂级数系数逐项比较论证（令 $\theta\to0$ 递推 $u(0)=u(1)=\cdots=0$）。(   T   )

91. $U[0,\theta]$ 的 $X_{(n)}$ 是完备充分统计量。(   T   )

92. 正则指数分布类的支撑集 $S$ 不依赖于 $\theta$；$U[0,\theta]$ 因支撑依赖 $\theta$ 故**不**属于正则指数族。(   T   )

93. $p(\theta)$ 必须为 $\theta$ 的连续非平凡函数（非常数），这是正则指数族条件之一。(   T   )

94. 正则指数族中 $Y_1=\sum K(X_i)$ 为完备充分统计量。(   T   )

95. Lehmann-Scheffé 定理：完备充分统计量 $T$ 的无偏函数 $\varphi(T)$ 是唯一 MVUE。(   T   )

96. 完备充分统计量存在则唯一。(   F   )
    > 解析：样卷 Spring25 原题。完备充分统计量不唯一（一一对应变形仍完备充分）；只在"等价类"意义下唯一。

97. $\text{Beta}(\theta,1)$ 的完备充分统计量为 $\sum\ln X_i$。(   T   )

98. 正则指数族中 $E[K(X)]=-q'(\theta)/p'(\theta)$。(   T   )

99. 正则指数族单参数情形，完备充分统计量一定存在。(   T   )
    > 解析：样卷 Spring26 原题。正则指数族保证 $\sum K(X_i)$ 完备充分。

100. 拉普拉斯 $f(x;a,b)=\frac1{2b}e^{-|x-a|/b}$，$a$ 已知时属于正则指数族，完备充分统计量为 $\sum|X_i-a|$。(   T   )
     > 解析：HW7 Problem 1 结论；支撑不依赖参数、可写成指数族形式。

## 二、单选题（共 100 题，每题 3 分）

### A. 抽样分布与学生定理

1. 设 $X_1,\ldots,X_n\stackrel{iid}{\sim}N(\mu,\sigma^2)$。下列关于 $\bar X$ 与 $S^2$ 的结论，**错误**的是 (  D  )
   - A. $\bar X\sim N(\mu,\sigma^2/n)$
   - B. $\bar X$ 与 $S^2$ 独立
   - C. $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$
   - D. $\dfrac{\bar X-\mu}{S/\sqrt n}\sim N(0,1)$
   > 解析：D 应为 $t(n-1)$。

2. 设 $X\sim N(0,1)$，$Y\sim\chi^2(n)$ 独立。$T=X/\sqrt{Y/n}$，则 (  C  )
   - A. $E(T)=0$ 对一切 $n$ 成立
   - B. $T^2\sim\chi^2(1)$
   - C. $T^2\sim F(1,n)$ 且 $n=1$ 时 $E(T)$ 不存在
   - D. $T$ 关于 $0$ 对称且方差恒为 $\dfrac{n}{n-2}$
   > 解析：A 错（$n=1$ 例外）；B 错（$T^2$ 是 $F$）；D 对 $n>2$ 成立但"恒"不严谨；C 正确。

3. 关于 $F$ 分布分位数，正确的是 (  B  )
   - A. $F_\alpha(n_1,n_2)=F_\alpha(n_2,n_1)$
   - B. $F_{1-\alpha}(n_1,n_2)=\dfrac{1}{F_\alpha(n_2,n_1)}$
   - C. $F_{1-\alpha}(n_1,n_2)=-F_\alpha(n_1,n_2)$
   - D. $F$ 分布关于 $0$ 对称
   > 解析：B 是标准恒等式。

4. $\chi^2(n)$ 与 $\Gamma$ 的关系是 (  C  )
   - A. $\chi^2(n)=\Gamma(n,2)$
   - B. $\chi^2(n)=\Gamma(n/2,1)$
   - C. $\chi^2(n)=\Gamma(n/2,2)$
   - D. $\chi^2(n)=\Gamma(2,n)$
   > 解析：$\chi^2(n)=\Gamma(n/2,2)$，形状 $n/2$、尺度 $2$。

5. 若 $X_1,\ldots,X_n\stackrel{iid}{\sim}\text{Exp}(\theta)$（rate $\theta$），关于 $Y=\sum X_i$ 说法正确的是 (  A  )
   - A. $Y\sim\Gamma(n,1/\theta)$，$E(Y)=n/\theta$，$\text{Var}(Y)=n/\theta^2$
   - B. $Y\sim\Gamma(n,\theta)$，$E(Y)=n\theta$
   - C. $2\theta Y\sim\chi^2(2n)$ 仅当 $n=1$ 成立
   - D. $Y$ 与 $\bar X$ 不独立
   > 解析：A 正确；C 错（$2\theta Y\sim\chi^2(2n)$ 对任意 $n$ 成立）；D 错（$\bar X=Y/n$ 是 $Y$ 的函数）。


6. 设 $X_1,\ldots,X_n\stackrel{iid}{\sim}N(\mu,\sigma^2)$，$\sigma^2$ 未知，检验 $H_0:\mu=\mu_0$。在显著水平 $\alpha$ 下拒绝域为 (  C  )
   - A. $|Z|>z_{\alpha/2}$，$Z=\dfrac{\bar X-\mu_0}{\sigma/\sqrt n}$
   - B. $|\bar X-\mu_0|>z_{\alpha/2}\dfrac{S}{\sqrt n}$
   - C. $|t|>t_{\alpha/2}(n-1)$，$t=\dfrac{\bar X-\mu_0}{S/\sqrt n}$
   - D. $\chi^2>\chi^2_\alpha(n-1)$
   > 解析：$\sigma$ 未知用 t 检验，自由度 $n-1$。

7. 设 $X_1,\ldots,X_n\stackrel{iid}{\sim}N(\mu,\sigma^2)$。下列统计量中**不是**充分统计量的是 (  B  )
   - A. $\bar X$（$\sigma^2$ 已知）
   - B. $\dfrac{X_1+2X_2}{3}$（$\sigma^2$ 已知，$n\ge3$）
   - C. $(\sum X_i,\sum X_i^2)$（$\mu,\sigma^2$ 均未知）
   - D. $\sum X_i$（$\sigma^2$ 已知）
   > 解析：样卷风格题。B 只用了两个观测，丢失了其余样本关于 $\theta$ 的信息，不充分。

8. 样本方差 $S^2=\dfrac1{n-1}\sum(X_i-\bar X)^2$ 是 $\sigma^2$ 的无偏估计，其分布满足 (  D  )
   - A. $S^2\sim\chi^2(n-1)$
   - B. $(n-1)S^2\sim\chi^2(n-1)$
   - C. $\dfrac{S^2}{\sigma^2}\sim\chi^2(n-1)$
   - D. $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$
   > 解析：D 是学生定理 (c)。

9. 关于样本方差的无偏性，正确的是 (  A  )
   - A. $E\!\left[\dfrac1{n-1}\sum(X_i-\bar X)^2\right]=\sigma^2$
   - B. $E\!\left[\dfrac1n\sum(X_i-\bar X)^2\right]=\sigma^2$
   - C. 分母 $n$ 与 $n-1$ 给出的估计量期望相同
   - D. $\bar X$ 与 $S^2$ 的协方差非零
   > 解析：A 正确；B 有偏（期望 $(n-1)\sigma^2/n$）；D 错（学生定理保证独立）。

10. 两独立正态样本，方差齐性检验 $H_0:\sigma_1^2=\sigma_2^2$ 用 (  B  )
    - A. t 检验
    - B. F 检验，统计量 $F=S_1^2/S_2^2\sim F(n_1-1,n_2-1)$
    - C. $\chi^2$ 检验
    - D. LRT 但退化为 Z 检验
    > 解析：方差比用 F 检验。

### B. Fisher 信息量 / RCB / 有效性

11. 设 $X\sim\text{Po}(\theta)$，则 $I(\theta)$ 为 (  B  )
    - A. $\dfrac{1}{\theta^2}$
    - B. $\dfrac{1}{\theta}$
    - C. $\theta$
    - D. $\dfrac{1}{\theta(1-\theta)}$
    > 解析：$\text{Po}(\theta)$ 的 $I(\theta)=1/\theta$。

12. 设 $X\sim\text{Bernoulli}(\theta)$，则 $I(\theta)$ 为 (  C  )
    - A. $\dfrac{1}{\theta}$
    - B. $\theta(1-\theta)$
    - C. $\dfrac{1}{\theta(1-\theta)}$
    - D. $\dfrac{n}{\theta(1-\theta)}$
    > 解析：C 是单观测信息量；D 是样本总信息量 $nI_1$。

13. 关于 Fisher 信息量 $I(\theta)$ 的说法，**正确**的是 (  A  )
    - A. $I(\theta)=\text{Var}\!\left(\dfrac{\partial\ln f}{\partial\theta}\right)=-E\!\left[\dfrac{\partial^2\ln f}{\partial\theta^2}\right]\ge0$
    - B. $I(\theta)$ 可取负值
    - C. $I(\theta)$ 恒等于 $\text{Var}(X)$
    - D. $I(\theta)$ 与参数化无关
    > 解析：A 是三式等价且非负；B 错；C 错；D 错（参数化改变信息量）。

14. 关于 Rao-Cramer 下界，**错误**的是 (  C  )
    - A. $\text{Var}(Y)\ge\dfrac{[k'(\theta)]^2}{nI(\theta)}$ 仅对无偏估计成立
    - B. $k(\theta)=\theta$ 时下界为 $\dfrac{1}{nI(\theta)}$
    - C. 任何估计量（含有偏）的方差都不低于 RCB
    - D. 下界证明用 Cauchy-Schwarz 估计 $\text{Cov}(Y,\sum\partial\ln f/\partial\theta)$
    > 解析：样卷 Spring24 考过；C 错，RCB 只约束无偏估计。

15. 关于"有效估计量"，正确的是 (  B  )
    - A. 有效估计量一定存在
    - B. 有效 $\Rightarrow$ MVUE，反之不然
    - C. MVUE 一定有效
    - D. 有效估计量不唯一
    > 解析：样卷 Spring25 原题。有效估计达到 RCB 必唯一，且是 MVUE；反之 MVUE 未必达 RCB。

16. 设 $X_1,\ldots,X_n\sim\text{Exp}(\theta)$（rate $\theta$），$\hat\theta=1/\bar X$。下列正确的是 (  C  )
    - A. $\hat\theta$ 无偏
    - B. $\hat\theta$ 达到 RCB
    - C. $\hat\theta$ 有偏，但渐近无偏
    - D. $\text{Var}(\hat\theta)=\dfrac{1}{nI(\theta)}=\dfrac{\theta^2}{n}$
    > 解析：$E[1/\bar X]\ne\theta$（有偏）；$n\bar X\sim\Gamma(n,1/\theta)$，$E[1/\bar X]=\dfrac{n\theta}{n-1}$，渐近无偏。

17. 设 $X_1,\ldots,X_n\sim N(\mu_0,\theta)$（$\mu_0$ 已知，$\theta$ 为方差）。$\hat\theta=\dfrac1n\sum(X_i-\mu_0)^2$，则 (  D  )
    - A. $I(\theta)=\dfrac{1}{\theta^2}$
    - B. $\hat\theta$ 有偏
    - C. RCB $=\dfrac{\theta^2}{n}$
    - D. $I(\theta)=\dfrac{1}{2\theta^2}$，$\hat\theta$ 无偏且有效，RCB $=\dfrac{2\theta^2}{n}$
    > 解析：D 正确；$\sum(X_i-\mu_0)^2/\theta\sim\chi^2(n)$，$\text{Var}(\hat\theta)=\dfrac{2\theta^2}{n}=$ RCB。

18. 设 $X_1,\ldots,X_n\sim\Gamma(\alpha_0,\beta)$（$\alpha_0$ 已知，估 $\beta$）。$\hat\beta=\bar X/\alpha_0$，则 (  B  )
    - A. $I(\beta)=\dfrac{1}{\beta^2}$，$\hat\beta$ 有偏
    - B. $I(\beta)=\dfrac{\alpha_0}{\beta^2}$，$\hat\beta$ 无偏且有效
    - C. RCB $=\dfrac{\beta^2}{n\alpha_0}$ 且 $\hat\beta$ 不达下界
    - D. $\text{Var}(\hat\beta)=\dfrac{\beta^2}{n}$
    > 解析：B 正确；$\text{Var}(\hat\beta)=\dfrac{\text{Var}(X)}{n\alpha_0^2}=\dfrac{\beta^2}{n\alpha_0}=\dfrac{1}{nI(\beta)}$。

19. 设 $X_1,X_2\sim\text{Po}(\theta)$，估计 $g(\theta)=\theta^2$，用 $Y=X_1X_2$。$Y$ 的有效性为 (  C  )
    - A. $\dfrac{1}{2\theta+1}$
    - B. $\dfrac{2\theta^3}{2\theta^3+\theta^2}$
    - C. $\dfrac{2\theta}{2\theta+1}$
    - D. $1$
    > 解析：Ass5 Problem 6。$\text{Var}(Y)=2\theta^3+\theta^2$，RCB$=\dfrac{(2\theta)^2}{2\cdot(1/\theta)}=2\theta^3$，效率$=\dfrac{2\theta^3}{2\theta^3+\theta^2}=\dfrac{2\theta}{2\theta+1}$。

20. 设 $X_1,\ldots,X_n\sim N(\theta,1)$，$\bar X$ 是 $\theta$ 的估计。则 (  A  )
    - A. $I(\theta)=1$，RCB $=\dfrac1n$，$\text{Var}(\bar X)=\dfrac1n$，有效
    - B. $\bar X$ 有偏
    - C. $I(\theta)=\dfrac{1}{\theta}$
    - D. $\bar X$ 是 MVUE 但不有效
    > 解析：A 正确，$\sigma_0^2=1$，$I=1/\sigma_0^2=1$。

21. 关于"有效性 $\text{eff}(Y)$"的说法，正确的是 (  D  )
    - A. 可大于 1
    - B. 可为负
    - C. 对有偏估计仍定义在 $[0,1]$
    - D. 对无偏估计落在 $[0,1]$，等号 1 当且仅当达到 RCB
    > 解析：$\text{eff}=\dfrac{\text{RCB}}{\text{Var}}\le1$（无偏估计）；有偏时不这样定义。

22. 拉普拉斯 $f(x;\theta)=\tfrac12 e^{-|x-\theta|}$ 的 Fisher 信息量为 (  B  )
    - A. $\dfrac{1}{\theta^2}$
    - B. $1$（常数）
    - C. $\theta$
    - D. 不存在
    > 解析：location family 信息量为常数；本题 $I(\theta)=1$。

23. 关于得分函数 $S(\theta)=\partial\ln f/\partial\theta$，正确的是 (  C  )
    - A. $E[S(\theta)]=1$
    - B. $\text{Var}(S(\theta))=0$
    - C. 正则条件下 $E[S(\theta)]=0$，$\text{Var}(S(\theta))=I(\theta)$
    - D. $S(\theta)$ 不依赖样本
    > 解析：C 是核心恒等式。

24. 关于 Location Family，正确的是 (  B  )
    - A. 其 Fisher 信息量依赖于 $\theta$
    - B. $f(x;\theta)=h(x-\theta)$ 时 $I(\theta)$ 与 $\theta$ 无关
    - C. 拉普拉斯、Logistic 都不属于 location family
    - D. MLE 必为 $\bar X$
    > 解析：B 正确；拉普拉斯/Logistic 都是 location family，MLE 分别为 $Q_2$ 与数值解。

25. 关于二阶导恒等式 $I(\theta)=-E[\partial^2\ln f/\partial\theta^2]$，正确的是 (  A  )
    - A. 需正则条件（积分与求导可交换）才成立
    - B. 对任何分布恒成立
    - C. 与定义式 $I=E[(\partial\ln f)^2]$ 不相等
    - D. 仅对离散分布成立
    > 解析：A 正确；正则条件下两式相等。

26. 对 $k(\theta)$ 的无偏估计 $Y$，RCB 形式为 (  D  )
    - A. $\dfrac{1}{nI(\theta)}$
    - B. $\dfrac{k(\theta)}{nI(\theta)}$
    - C. $\dfrac{k'(\theta)}{nI(\theta)}$
    - D. $\dfrac{[k'(\theta)]^2}{nI(\theta)}$
    > 解析：D 是一般形式；A 是 $k(\theta)=\theta$ 特例。

27. 关于 $\text{Beta}(\theta,1)$ 的纠偏估计 $\tilde\theta=\dfrac{n-1}{n}\hat\theta$，正确的是 (  C  )
    - A. 是有效估计量
    - B. 方差等于 RCB
    - C. 渐近有效 $\text{eff}\to1$，但有限样本不达 RCB
    - D. 不是无偏估计
    > 解析：C 正确；$\tilde\theta$ 无偏但有限样本 $\text{eff}=\dfrac{n-2}{n}<1$。

28. 关于"相合性"与"渐近正态性"，正确的是 (  A  )
    - A. MLE 相合 $\hat\theta\xrightarrow{P}\theta_0$，且 $\sqrt{nI_1(\theta_0)}(\hat\theta-\theta_0)\xrightarrow{d}N(0,1)$
    - B. 相合意味着无偏
    - C. 渐近正态要求 $n=1$
    - D. MLE 不一定相合
    > 解析：A 正确；B 错（相合≠无偏）；D 错（正则条件下 MLE 相合）。

29. 关于 MLE 不变性，正确的是 (  D  )
    - A. 仅对线性 $g$ 成立
    - B. 要求 $g$ 单调
    - C. 仅对单参数成立
    - D. $\widehat{g(\theta)}=g(\hat\theta)$，对任意（可测）函数 $g$ 成立，多参数亦然
    > 解析：D 正确，Hogg Theorem 6.1.2。

30. 关于 $U[0,\theta]$ 的 MLE $\hat\theta=X_{(n)}$，正确的是 (  B  )

    - B. $\hat\theta$ 有偏，$E[\hat\theta]=\dfrac{n}{n+1}\theta$；纠偏后 $\dfrac{n+1}{n}X_{(n)}$ 是 MVUE
    - C. $\hat\theta$ 达到 RCB

### C. MLE / 相合性

    - B. $\dfrac{X_{(1)}+X_{(n)}}{2}$
    - C. 样本中位数 $Q_2$

    > 解析：C 正确；中位数最小化 $\sum|X_i-\theta|$。

32. $\text{Exp}(\theta)$（rate $\theta$，p.d.f. $\theta e^{-\theta x}$）的 MLE 为 (  A  )
    - A. $\hat\theta=\dfrac{1}{\bar X}$
    - B. $\hat\theta=\bar X$
    - C. $\hat\theta=\dfrac{n}{\sum\ln X_i}$
    - D. $\hat\theta=\bar X/\alpha_0$
    > 解析：A 正确；$l=n\ln\theta-\theta\sum X_i$，$l'=n/\theta-\sum X_i=0$。

33. $\text{Beta}(\theta,1)$（$f=\theta x^{\theta-1}$）的 MLE 为 (  D  )

    - B. $1/\bar X$
    - C. $-\sum\ln X_i/n$ 的倒数写作 $\bar X$
    - D. $\hat\theta=-\dfrac{n}{\sum\ln X_i}$
    > 解析：D 正确；$l=n\ln\theta+(\theta-1)\sum\ln X_i$，$l'=n/\theta+\sum\ln X_i=0$。

34. $\Gamma(\alpha_0,\beta)$（$\alpha_0$ 已知，估 $\beta$）的 MLE 为 (  B  )

    - B. $\hat\beta=\bar X/\alpha_0$
    - C. $\hat\beta=\alpha_0/\bar X$

    > 解析：B 正确；$E[X]=\alpha_0\beta$，MLE 矩估计一致。

    - C. 无显示解，需数值方法

    > 解析：C 正确；与拉普拉斯不同，Logistic MLE 无显示解。

36. 若参数空间限制 $\theta\in[0,1/3]$，$\text{Bernoulli}(\theta)$ 的 MLE 为 (  D  )

    - B. $\min\{\bar X,1/2\}$
    - C. $\max\{\bar X,0\}$
    - D. $\min\{\bar X,1/3\}$
    > 解析：D 正确；似然在 $\bar X$ 取极值，受上界 $1/3$ 截断。

37. 设 $X_1,\ldots,X_n\sim N(\mu_0,\theta)$（$\mu_0$ 已知，估方差 $\theta$）。MLE 为 (  A  )
    - A. $\hat\theta=\dfrac1n\sum(X_i-\mu_0)^2$

### D. 似然比检验 / Wald / Score

41. 似然比检验统计量 $\Lambda=\dfrac{L(\theta_0)}{L(\hat\theta)}$，其拒绝域 $\Lambda\le c$ 的直观含义是 (  B  )
    - A. $L(\theta_0)$ 比 $L(\hat\theta)$ 大
    - B. $\theta_0$ 处的似然相对 MLE 处的似然足够小，说明数据不支持 $H_0$
    - C. $\hat\theta$ 与 $\theta_0$ 重合
    - D. 得分 $l'(\theta_0)=0$
    > 解析：B 正确；$\Lambda\le1$，越小越偏离 $H_0$。

42. 在正则条件下，$H_0:\theta=\theta_0$ 成立时 $-2\ln\Lambda$ 的渐近分布为 (  C  )
    - A. $N(0,1)$
    - B. $\chi^2(n)$
    - C. $\chi^2(1)$
    - D. $F(1,n-1)$
    > 解析：单参数单约束，自由度 1。

43. Wald 检验统计量 $\chi^2_W=nI(\hat\theta)(\hat\theta-\theta_0)^2$ 的特点是 (  D  )
    - A. 需在 $\theta_0$ 处求导
    - B. 需同时拟合约束与无约束模型
    - C. 无需 MLE
    - D. 只需无约束 MLE $\hat\theta$，在 $\hat\theta$ 处估计信息
    > 解析：D 正确；Wald 度量 $\hat\theta$ 离 $\theta_0$ 的距离。

44. Score 检验统计量 $\chi^2_R=\dfrac{[l'(\theta_0)]^2}{nI(\theta_0)}$ 的特点是 (  A  )
    - A. 只需在 $\theta_0$ 处求导，无需无约束 MLE
    - B. 必须先求 $\hat\theta$
    - C. 度量 $\hat\theta$ 与 $\theta_0$ 的距离
    - D. 与 Wald 恒等
    > 解析：A 正确；Score 度量 $\theta_0$ 处得分偏离 0 的程度。

45. 关于三大检验（LRT/Wald/Score）的关系，正确的是 (  C  )
    - A. 三者有限样本下恒等
    - B. 三者自由度各不相同
    - C. 大样本下渐近等价，自由度都等于约束个数
    - D. LRT 只需无约束 MLE
    > 解析：C 正确；三者有限样本一般不等，渐近等价。

46. 设 $X_1,\ldots,X_n\sim N(\theta,\sigma_0^2)$，$\sigma_0^2$ 已知，检验 $H_0:\theta=\theta_0$ 的 LRT 拒绝域等价于 (  A  )
    - A. $|Z|>z_{\alpha/2}$，$Z=\dfrac{\bar X-\theta_0}{\sigma_0/\sqrt n}$
    - B. $|t|>t_{\alpha/2}(n-1)$
    - C. $\chi^2>\chi^2_\alpha(n)$
    - D. $F>F_\alpha(1,n-1)$
    > 解析：A 正确；方差已知时 LRT 即 Z 检验。

47. 设 $X_1,\ldots,X_n\sim\text{Exp}(\theta)$（rate $\theta$），检验 $H_0:\theta=\theta_0$。在 $H_0$ 下 (  B  )
    - A. $2n\bar X/\theta_0\sim\chi^2(2n)$
    - B. $2n\theta_0\bar X\sim\chi^2(2n)$
    - C. $\bar X\sim N(1/\theta_0,1/(n\theta_0^2))$ 仅
    - D. $n\theta_0\bar X\sim\chi^2(n)$
    > 解析：B 正确；$\sum X_i\sim\Gamma(n,1/\theta_0)$，$2\theta_0\sum X_i=2n\theta_0\bar X\sim\chi^2(2n)$。

48. 设 $X_1,\ldots,X_n\sim\text{Bernoulli}(\theta)$，检验 $H_0:\theta=1/3$。Score 检验统计量为 (  D  )
    - A. $\dfrac{n(\bar X-1/3)^2}{\bar X(1-\bar X)}$
    - B. $(1/3)^Y(2/3)^{n-Y}/[\bar X^Y(1-\bar X)^{n-Y}]$
    - C. $n(\bar X-1/3)^2$
    - D. $\dfrac{n(3\bar X-1)^2}{2}$
    > 解析：D 正确（Ass5 P10）；$I(\theta_0)=9/2$，$\chi^2_R=\dfrac{[l'(\theta_0)]^2}{n\cdot 9/2}=\dfrac{n(3\bar X-1)^2}{2}$。

49. 设 $X_1,\ldots,X_n\sim\text{Po}(\theta)$，检验 $H_0:\theta=5$。Wald 统计量为 (  B  )
    - A. $\dfrac{n(\bar X-5)^2}{5}$
    - B. $\dfrac{n(\bar X-5)^2}{\bar X}$
    - C. $2n(\bar X\ln(\bar X/5)+5-\bar X)$

64. 下面的估计量中，**是** $\theta$ 的 MVUE 的是 (  C  )

    > 解析：A 正确；N-P 引理针对简单 vs 简单。

92. 关于最优拒绝域的"无偏性"，正确的是 (  B  )
    - A. 无偏指 $P_{\theta_0}(\text{拒绝})=0$
    - B. $P_\theta(\mathbf X\in C)\ge\alpha$ 对所有 $\theta\in\omega_1$；N-P 最优拒绝域必无偏
    - C. 无偏检验功效为 0
    - D. 与功效函数无关
    > 解析：B 正确（Hogg Corollary 8.1.1）。

93. 关于 UMP（一致最优势）检验，正确的是 (  C  )
    - A. 任何检验问题都存在 UMP
    - B. 双边检验 $H_0:\theta=\theta_0$ vs $H_1:\theta\ne\theta_0$ 一定存在 UMP
    - C. 单边检验 $H_0:\theta\le\theta_0$ vs $H_1:\theta>\theta_0$ 在 MLR 下存在 UMP
    - D. UMP 不依赖检验统计量
    > 解析：C 正确；双边一般不存在 UMP（B 错）。

94. 关于单调似然比（MLR），正确的是 (  A  )
    - A. 若似然比 $L(\theta')/L(\theta'')$（$\theta'<\theta''$）关于 $Y$ 单调，则单边检验存在 UMP
    - B. MLR 要求似然比为常数
    - C. MLR 与 Karlin-Rubin 无关
    - D. 双边检验才有 MLR
    > 解析：A 正确；MLR 是 Karlin-Rubin 定理的前提。

95. Karlin-Rubin 定理：若似然比关于 $Y$ 单调递减，则 $H_0:\theta=\theta'$ vs $H_1:\theta>\theta'$ 的 UMP 拒绝域形如 (  B  )
    - A. $\{Y\le c_1\}$
    - B. $\{Y\ge c_1\}$，$P_{\theta'}(Y\ge c_1)=\alpha$
    - C. $\{|Y|\ge c\}$
    - D. $\{Y=0\}$
    > 解析：B 正确；递减 $\Rightarrow$ 大 $Y$ 偏向 $H_1$（大 $\theta$）。

96. 设 $X_1,\ldots,X_n\sim N(\theta,1)$，检验 $H_0:\theta\le\theta_0$ vs $H_1:\theta>\theta_0$。UMP 拒绝域为 (  A  )
    - A. $\{\sum X_i\ge n\theta_0+\sqrt n\,z_\alpha\}$
    - B. $\{\sum X_i\le n\theta_0-\sqrt n\,z_\alpha\}$
    - C. $\{|\sum X_i-n\theta_0|\ge\sqrt n\,z_{\alpha/2}\}$
    - D. $\{\sum X_i^2\ge c\}$
    > 解析：A 正确；右尾单边，$z_\alpha$ 单侧分位数。

97. 设 $X_1,\ldots,X_n\sim N(0,\theta)$（均值已知 0，估方差 $\theta$），检验 $H_0:\theta\le\theta_0$ vs $H_1:\theta>\theta_0$。UMP 拒绝域为 (  C  )
    - A. $\{\sum X_i\ge c\}$
    - B. $\{\sum X_i^2\le c\}$
    - C. $\{\sum X_i^2\ge\theta_0\chi^2_\alpha(n)\}$
    - D. $\{|\bar X|\ge c\}$
    > 解析：C 正确；$\sum X_i^2/\theta_0\sim\chi^2(n)$（$H_0$ 下）。

98. 关于双边检验 $H_0:\theta=\theta_0$ vs $H_1:\theta\ne\theta_0$ 的 UMP，正确的是 (  D  )
    - A. 一定存在
    - B. 等于左尾 UMP
    - C. 等于右尾 UMP
    - D. 一般**不存在**（左尾与右尾 UMP 拒绝域不同，无法统一）
    > 解析：D 正确；正态双边检验无 UMP，需用 GLRT/无偏检验。

99. 关于广义似然比检验（GLRT），正确的是 (  B  )
    - A. 仅适用于简单假设
    - B. $\Lambda=\dfrac{\sup_{\theta\in\Omega_0}L(\theta)}{\sup_{\theta\in\Omega}L(\theta)}$，$-2\ln\Lambda\xrightarrow{d}\chi^2(r)$，$r=\dim\Omega-\dim\Omega_0$
    - C. 自由度为 $n$
    - D. 不需 MLE
    > 解析：B 正确；$r$ 为约束维度差。

100. 设 $X_1,\ldots,X_n\sim\text{Bernoulli}(\theta)$，检验 $H_0:\theta\le\theta_0$ vs $H_1:\theta>\theta_0$。UMP 拒绝域形如 (  C  )
     - A. $\{\sum X_i\le c\}$
     - B. $\{|\sum X_i-n\theta_0|\ge c\}$
     - C. $\{\sum X_i\ge c_1\}$，$P_{\theta_0}(\sum X_i\ge c_1)=\alpha$
     - D. $\{\bar X=\theta_0\}$
     > 解析：C 正确；似然比关于 $\sum X_i$ 单调递减，右尾拒绝。
