## problem 8-11

### 题目描述

改写以深度优先查找法遍历给定的连通图的DFS程序。要求不用递归方法，而用一个栈来实现。

### 算法设计思路

深度优先搜索（DFS）通常使用递归实现，利用系统栈来保存调用上下文。为了将其改为非递归，我们需要显式地使用数据结构栈（`std::stack`）来模拟这一过程。

1.  **数据结构定义**：
    *   定义一个 `state` 结构体，包含当前正在访问的顶点下标 `u` 和当前遍历到的边节点指针 `cur`。这相当于保存了递归函数中的局部变量和执行进度。
    *   使用 `std::stack<state> s` 作为工作栈。
    *   使用 `visited` 数组记录已访问的顶点。

2.  **算法流程**：
    *   **初始化**：获取起始顶点的下标，将其标记为已访问，输出该顶点，并将初始状态 `{startPos, NodeTable[startPos].adj}` 压入栈。
    *   **循环处理**：当栈不为空时，获取栈顶元素的引用 `top`。
    *   **寻找邻接点**：
        *   检查 `top.cur` 指向的边。如果该边指向的顶点已经被访问过，则通过 `top.cur = top.cur->link` 跳过，直到找到一个未访问的邻接点或链表结束。
    *   **推进或回溯**：
        *   **推进（Push）**：如果找到了未访问的邻接点 `v`，标记 `v` 为已访问，输出 `v`。关键步骤是：先将当前栈顶的 `cur` 指针后移（`top.cur = top.cur->link`），以便回溯时能从下一条边开始；然后将新顶点的状态 `{v, NodeTable[v].adj}` 压入栈。
        *   **回溯（Pop）**：如果当前顶点没有更多未访问的邻接点（`top.cur` 为空），则执行 `s.pop()`，回退到上一个顶点。

### 测试与结果

**测试用例**：
构建一个包含 4 个顶点的图，插入以下边（注意代码中使用头插法建立邻接表）：
*   A -> B (权值 10)
*   A -> C (权值 20)
*   B -> D (权值 30)
*   C -> D (权值 40)
*   D -> A (权值 50)

## problem 8-14

### 题目描述

根据 Kruskal 算法，编写一个在连通的带权无向图中寻找一棵最小代价生成树的程序。

### 算法设计思路

Kruskal 算法是一种贪心算法，其核心思想是按照权值从小到大的顺序选择边，如果选中的边不会与已选的边构成环，则将其加入最小生成树。

1.  **边的存储与排序**：
    *   定义 `Edge` 结构体存储边的两个端点 `i, j` 和权值 `data`。
    *   使用 `std::priority_queue` 配合自定义比较器 `CompareEdge`（实现最小堆），将图中所有边加入队列。这样每次 `pop()` 出来的都是当前权值最小的边。

2.  **环的检测（并查集）**：
    *   使用 `UnionFound` 数组维护连通分量。初始时 `UnionFound[i] = i`，每个顶点自成一个集合。
    *   实现 `Found(i)` 函数查找顶点 `i` 所属集合的根节点。
    *   在选择边 `(u, v)` 时，比较 `Found(u)` 和 `Found(v)`。如果相等，说明两点已连通，加入该边会构成环；如果不等，说明安全。

3.  **算法流程**：
    *   初始化结果集 `result` 和并查集。
    *   将图中所有边（注意无向图只存一次 `i > j`）压入优先队列。
    *   循环直到选够 `VerticesNum - 1` 条边或队列为空：
        *   取出堆顶最小边。
        *   若该边连接的两个顶点属于不同集合：
            *   将边加入 `result`。
            *   合并两个集合（`UnionFound[rootJ] = rootI`）。
            *   计数器加 1。

## problem 9-8

### 题目描述

输入 40 个学生的记录（每个学生的记录包括学号和成绩），组成记录数组，然后按成绩由高到低的次序输出（每行 5 个记录）。排序方法采用选择排序。

### 算法设计思路

1.  **数据结构**：
    *   定义 `student` 结构体，包含 `string number` 和 `int score`。
    *   重载 `operator<` 和 `operator>` 用于比较成绩。
    *   重载 `operator<<` 用于格式化输出 `{学号 成绩}`。

2.  **选择排序（Selection Sort）**：
    *   算法要求按成绩**由高到低**（降序）排序。
    *   外层循环 `i` 从 `0` 到 `n-2`，表示当前要确定的位置。
    *   内层循环 `j` 从 `i+1` 到 `n-1`，在未排序部分寻找**最大值**的下标 `maxIndex`。
    *   如果 `maxIndex` 不等于 `i`，则交换 `arr[i]` 和 `arr[maxIndex]`。

3.  **输出格式控制**：
    *   遍历排序后的数组。
    *   使用计数器 `i`，每输出一个记录后 `++i`。
    *   判断 `if (i % 5 == 0)` 输出换行符 `endl`，实现每行 5 个记录。
