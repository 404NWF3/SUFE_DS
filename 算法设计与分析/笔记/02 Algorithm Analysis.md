# 重点

#### 1. 计算的可行性 (Computational Tractability)

*   **计算模型**：我们通常基于 **Word RAM 模型**进行分析，在这个模型下，基本的算术运算、内存读写、数组索引、指针跳转等操作都消耗**常数时间 $O(1)$**。
*   **多项式时间 (Polynomial Time)**：如果一个算法在最坏情况下的运行时间存在常数 $a > 0$ 和 $b > 0$，使得其步数被 $a \cdot n^b$ 框定，我们就称它是“高效的”。多项式时间算法具有极好的缩放特性：输入规模翻倍，运行时间最多增加一个常数倍。
*   **最坏情况分析 (Worst-case Analysis)**：课程中绝大多数算法采用最坏情况分析，即对**任何**大小为 $n$ 的输入都能提供时间保证。偶尔也会有例外（如单纯形法在最坏情况下是指数级，但在实践中极其高效）。

#### 2. 渐近增长阶数 (Asymptotic Order of Growth)

*   **大 $O$ 记号（渐近上界）**：$f(n)$ 是 $O(g(n))$，意味着存在常数 $c > 0$ 和 $n_0 \ge 0$，使得当 $n \ge n_0$ 时，$0 \le f(n) \le c \cdot g(n)$。
*   **大 $\Omega$ 记号（渐近下界）**：$f(n)$ 是 $\Omega(g(n))$，意味着存在常数 $c > 0$ 和 $n_0 \ge 0$，使得当 $n \ge n_0$ 时，$f(n) \ge c \cdot g(n) \ge 0$。
*   **大 $\Theta$ 记号（紧确界）**：$f(n)$ 是 $\Theta(g(n))$，意味着它同时满足 $O$ 和 $\Omega$ 的条件，即被夹在 $c_1 \cdot g(n)$ 和 $c_2 \cdot g(n)$ 之间。
*   **基于极限的判断**：如果 $\lim_{n \to \infty} \frac{f(n)}{g(n)} = c > 0$，那么 $f(n)$ 是 $\Theta(g(n))$。如果是 $0$，则是 $O$ 但不是 $\Omega$。
*   **常见函数比较**：对数函数（底数可忽略，$\log_a n$ 是 $\Theta(\log_b n)$）总是被任意正数次幂的多项式“碾压”（$\log_a n = O(n^d)$）；多项式又总是被指数级“碾压”（$n^d = O(r^n)$）。阶乘 $n!$ 是 $2^{\Theta(n \log n)}$（sterling公式），比普通指数更糟。

#### 3. 常见运行时间模式 (Survey of Common Running Times)
*   **$O(n)$ 线性时间**：例如合并两个有序列表、利用有序性寻找“目标和 (TARGET-SUM)”（左右指针夹逼）。
*   **$O(\log n)$ 对数时间**：例如二分查找、在旋转有序数组中寻找最小值。
*   **$O(n \log n)$ 线性对数时间**：例如归并排序、寻找最大空闲时间间隔（先排序后遍历）。
*   **$O(n^2)$ 与 $O(n^3)$**：遍历所有节点对（如平面最近点对的暴力解法）或三元组（如 3-SUM 的暴力解法）。
*   **$O(2^{cn})$ 指数时间**：如暴力求图的最大独立集，或枚举全排列（TSP问题）。

# 坑

## 坑 1：大 O 记号的“宽松性”

**题目**：已知函数 $f(n) = 3n^2 + 17n \log_2 n + 1000$。以下哪个选项是正确的？
A. $f(n)$ 是 $O(n^2)$，但不是 $O(n^3)$
B. $f(n)$ 既不是 $O(n^2)$ 也不是 $O(n^3)$
C. $f(n)$ 是 $O(n^3)$，但不是 $O(n^2)$
D. $f(n)$ 同时是 $O(n^2)$ 和 $O(n^3)$

**正确答案：D**。
*易错点*：把大 $O$ 和大 $\Theta$（紧确界）混淆，认为 $f(n)$ 的最高次项是 $n^2$，所以它只能是 $O(n^2)$。
*解析*：大 $O$ 记号仅仅表示**渐近上界 (Upper bounds)**。只要 $f(n)$ 的增长速度不超过 $g(n)$ 的常数倍即可。既然 $f(n)$ 能够被 $c \cdot n^2$ 盖住，它自然也能被增长更快的 $c \cdot n^3$ 盖住。只有大 $\Theta$ 才严格要求必须是 $\Theta(n^2)$。

## 坑2：任意与无数个

**题目**：判断对错：只要存在一个常数 $c > 0$，使得对于**无限多个** $n$，都满足 $f(n) \ge c \cdot g(n) \ge 0$，我们就可以断定 $f(n)$ 是 $\Omega(g(n))$。

**正确答案：错误**。

*解析*：大 $\Omega$ 的严格定义是：必须存在常数 $c > 0$ 和 $n_0 \ge 0$，使得对于 **所有 (for all)** $n \ge n_0$，都满足 $f(n) \ge c \cdot g(n)$。如果是“无限多个 $n$”，这意味着函数可能会剧烈震荡，一会儿大一会儿小，这不符合渐近下界的定义。

## 坑 3：极限法则

**题目**：判断对错：如果极限 $\lim_{n \to \infty} \frac{f(n)}{g(n)}$ 不存在，那么 $f(n)$ 绝对不可能是 $O(g(n))$。

**正确答案：错误 (False)**。

*解析*：如果限 $\lim_{n\to \infty} \frac{f(n)}{g(n)} = c > 0$，可以推导出 $\Theta$ 关系。但**极限不存在不代表没有上界**，PPT 给出了一个经典的震荡函数反例：如果 $f(n) = n(2 + \sin n)$，而 $g(n) = n$。由于 $\sin n$ 在 $[-1, 1]$ 之间震荡，两者的比值极限不存在。但是我们显然可以找到常数 $c=3$ 使得 $n(2 + \sin n) \le 3n$ 永远成立，所以 $f(n)$ 完全满足 $O(n)$ 的定义。

## 坑 4：多变量与“隐藏的约束”

**题目**：图的广度优先搜索 (BFS) 运行时间通常写为 $O(m + n)$，其中 $n$ 是节点数，$m$ 是边数。现有一个算法，其运行时间为 $f(m,n) = 32mn^2 + 17mn + 32n^3$。因为这个多项式里有 $mn^2$，所以这个算法**无论在什么图上**都不可能是 $O(n^3)$ 的。

**正确答案：错误 (False)**。

*解析*：函数本身 $32mn^2 + 17mn + 32n^3$ 确实有 $mn^2$ 项。但是，在一个没有平行边和自环的图中，边数 $m$ 和节点数 $n$ 是存在约束的：**$m$ 最大不会超过 $n(n-1)/2$**，即 $m \le n^2$，对于全连接图 $m=\frac{n(n-1)}{2}$，那么 $f(m,n)=O(n^4)$ 了。

不过，如果问题的**前置条件 (precondition) 暗示了 $m \le n$**（例如这是一棵树或者极为稀疏的图），那么 $mn^2 \le n \cdot n^2 = n^3$。此时，$f(m,n)$ 就可以完美地被 $O(n^3)$ 框定。否则，在稠密图上，$f(m,n)$ 很有可能是 $\Omega(n^3)$ 的。

实际上，对于 $f(m,n) = 32mn^2 + 17mn + 32n^3$，它可以是 $O(mn^2+n^3)$ 或者 $O(mn^3)$，但它一定不是 $O(mn^2)$ 或 $O(n^3)$。如果有 $m \leq n$，那么 $O(n^3)$。

## 坑 5：指数时间

以下哪个是指数时间的等价定义？

A. $O(2^n)$
B. for some $c$，$O(2^{cn})$
C. Both A and B
D. Neither A nor B

**正确答案：B**。

解析：对于指数时间 $f(n) = 3^n$ 显然不是 $O(2^n)$ 的，而对于任意指数时间 $f(n) = a^n$，只要取 $c \geq \log_2a$ 即可，$f(n)$ 一定是 $O(2^{cn})$ 的。

**指数时间算法的典型特征**

1. 递归分解：问题被分解为多个子问题
2. 重复计算：相同的子问题被多次计算
3. 组合爆炸：子问题数量随输入规模呈指数增长
4. 无记忆性：不保存已解决的子问题结果

**从指数时间到多项式时间的改进策略**

1. 记忆化(Memoization)：存储已计算结果
2. 动态规划：自底向上构建解
3. 剪枝策略：提前终止不可能的分支
4. 启发式方法：利用问题特性减少搜索空间
5. 近似算法：接受近似解换取时间效率
