# 重点

-   **归并排序及其复杂度证明技巧**
	归并排序是分治法的经典应用：将数组分成两半，分别递归排序，然后将两个有序的数组合并。合并过程通过额外的辅助数组可以在 $O(n)$ 的时间内完成。
	其时间复杂度的递推关系式为：$T(n) = 2T(n/2) + n$ （当 $n>1$ 时，若 $n=1$ 则为 $0$）。
	-  **证明技巧**：
		1. **递归树法（Proof by Recursion Tree）**：
		   * **技巧核心**：通过画出递归树，计算每一层的计算量并将其求和。
		   * **证明过程**：树的第 $k$ 层有 $2^k$ 个子问题，每个子问题的规模为 $n/2^k$。在这一层合并的代价为 $2^k \times (n/2^k) = n$。因为每次规模减半，树的总层数为 $\log_2 n$。将每一层的代价 $n$ 累加，总时间即为 $n \log_2 n$。
		![[Pasted image 20260421215228.png]]
		2. **裂项相消法（Proof by Telescoping）**：
		   * **技巧核心**：通过对递推式的两边同时除以一个合适的值（此处为 $n$），将其转化为可以逐层抵消的等式。
		   * **证明过程**：将 $T(n) = 2T(n/2) + n$ 两边同除以 $n$，得到 $\frac{T(n)}{n} = \frac{T(n/2)}{n/2} + 1$。不断将其展开：$\frac{T(n/2)}{n/2} = \frac{T(n/4)}{n/4} + 1$，直至 $\frac{T(2)}{2} = \frac{T(1)}{1} + 1$。将这 $\log_2 n$ 个等式相加，等号两边相同的项互相抵消，最后得到 $\frac{T(n)}{n} = \frac{T(1)}{1} + \log_2 n$，即 $T(n) = O(n \log_2 n)$。
		3.  **数学归纳法（Proof by Induction）**：
		   * **技巧核心**：先猜测结论，再使用数学归纳法严格证明递推关系的正确性。这也是处理带向下取整/向上取整（$\lfloor n/2 \rfloor, \lceil n/2 \rceil$）的不规整边界最严谨的方法。
		   * **证明过程**：假设 $T(n) = O(n \log_2 n)$ 对小于 $2n$ 的数成立。证明 $T(2n)$ 时，代入公式 $T(2n) = 2T(n) + 2n = 2(n \log_2 n) + 2n = 2n(\log_2 n + 1) = 2n \log_2 (2n)$，原命题得证。针对 $n$ 不为2的幂的情况，通过定义 $n_1 = \lfloor n/2 \rfloor, n_2 = \lceil n/2 \rceil$，可以归纳证明 $T(n) \le n \lceil \log_2 n \rceil$。
		   * 对于一般的情况，假设 $T(n) = n \log_2 n$ 对任意 $m$，满足 $m < n$ 成立，代入公式：$T(n) \leq 2T( \frac{n}{2} ) + n \leq 2c\frac{n}{2}\log_2{\frac{n}{2}} + n = cn (\log_2(n)-1) + n \leq cn\log_2 n$ ，只要取 $c \geq 1$ 即可满足条件。所以 $T(n) = O(n\log_2 n)$

-   **主定理（Master Theorem）** 与通用递归树分析
	- 主定理主要用于求解如下形式的非负整数递归方程：$T(n) = aT(n/b) + \Theta(n^c)$。根据 $r = \frac{a}{b^c}$ 的取值，判断 $T(n)$ 的时间复杂度。

$$
T(n)=\left\{\begin{aligned}
&\Theta (n^c), \quad& r < 1 \\
&\Theta (n\log n), \quad& r=1 \\
&\Theta (n^{\log_b a}),  \quad& r > 1
\end{aligned}\right.
$$

- 其中各参数的定义与限制条件如下：
		*   **$a \ge 1$**：代表每次递归划分出的**子问题数量**，也即递归树的分支因子（branching factor）。
		*   **$b \ge 2$**：代表每次递归时**子问题规模缩小的比例**。
		*   **$c \ge 0$**：代表将问题分解以及合并子问题解所需要的**工作量阶数**（即 $f(n) = \Theta(n^c)$）。
		*   **边界条件**：通常假定 $T(0) = 0$ 且 $T(1) = \Theta(1)$。公式中的 $n/b$ 可以是向下取整 $\lfloor n/b \rfloor$ 或向上取整 $\lceil n/b \rceil$，这两种混合使用都不会影响主定理的最终结论。
	-   **递推树逐层计算**：
		主定理的成立依赖于递归树的逐层计算。假设 $n$ 是 $b$ 的幂：
		1.  **节点与规模**：递归树的总层数为 $1 + \log_b n$，在第 $i$ 层，共有 $a^i$ 个子问题，每个子问题的规模大小为 $n/b^i$。
		2.  **每一层的开销**：第 $i$ 层的总工作量为子问题个数乘以单个子问题的合并/分解开销，即 $a^i \times (n/b^i)^c = n^c (a/b^c)^i$。
		3.  **等比数列求和**：如果我们将比率定义为 **$r = a/b^c$**，那么整棵树的总代价就是对几何级数 $\sum r^i$ 的求和。
		根据几何级数的收敛性质（$r < 1$、$r = 1$、$r > 1$），可以推导出 $r < 1$ 等价于 $c > \log_b a$ 等数学关系，从而引出主定理的三大核心情况。

-   **三种情况**：
	-   **情况 1：根节点开销主导（Cost dominated by cost of root）**
		*   **条件**：当 **$c > \log_b a$**（即 $r < 1$）时。
		*   **结论**：递归树的计算量集中在最顶层，总时间复杂度为 **$T(n) = \Theta(n^c)$**。
		*   **实例**：$T(n) = 48T(\lfloor n/4 \rfloor) + n^3$。
			*   此处 $a = 48, b = 4, c = 3$。
			*   因为 $c = 3 > \log_4 48 \approx 2.7924$，属于情况 1。
			*   结果为 $T(n) = \Theta(n^3)$。
	-   **情况 2：各层开销均匀（Cost evenly distributed in tree）**
		*   **条件**：当 **$c = \log_b a$**（即 $r = 1$）时。
		*   **结论**：递归树每一层的开销大致相同，总层数约为 $\log_b n$，总时间复杂度为 **$T(n) = \Theta(n^c \log n)$**。
		*   **实例**：$T(n) = T(\lfloor n/2 \rfloor) + T(\lceil n/2 \rceil) + 17n$ （相当于 $a=2$）。
			*   此处 $a = 2, b = 2, c = 1$。
			*   因为 $c = 1 = \log_2 2$，属于情况 2。
			*   结果为 $T(n) = \Theta(n \log n)$。经典的归并排序（Mergesort）即属于此类。
	-   **情况 3：叶子节点开销主导（Cost dominated by cost of leaves）**
		*   **条件**：当 **$c < \log_b a$**（即 $r > 1$）时。
		*   **结论**：递归树的计算量随着层数向下呈指数级增长，绝大部分工作量集中在最底层的叶子节点，总时间复杂度由叶子节点数量决定，即 **$T(n) = \Theta(n^{\log_b a})$**。
		*   **实例**：$T(n) = 3T(\lfloor n/2 \rfloor) + 5n$。
			*   此处 $a = 3, b = 2, c = 1$。
			*   因为 $c = 1 < \log_2 3 \approx 1.5849$，属于情况 3。
			*   结果为 $T(n) = \Theta(n^{\log_2 3})$，即 $O(n^{1.58})$。
	-   **主定理不适用情况**：使用主定理的前提是递推式必须严格符合其标准形式。在以下几种情况下，主定理**无法直接适用**：
		1.  **子问题数量不是常数**：例如 $T(n) = nT(n/2) + n^2$，此时 $a=n$ 是一个变量而非固定常数。
		2.  **子问题数量小于 1**：例如 $T(n) = \frac{1}{2}T(n/2) + n^2$，不满足 $a \ge 1$ 的前提限制。
		3.  **分解与合并的开销不是多项式形式 $\Theta(n^c)$**：例如 $T(n) = 2T(n/2) + n \log n$，此处的 $f(n) = n \log n$，不符合单纯的 $n^c$ 形式，因此无法直接套用基本主定理。
	-   **定理扩展**：主定理中的渐进符号 $\Theta$ 在很多时候可以全局替换为 $O$（表示上界）或 $\Omega$（表示下界）。同时，我们可以忽略规模足够小的初始条件差异，即允许只要当 $n > n_0$ 时递推式成立，且对于所有 $n \le n_0$ 满足 $T(n) = \Theta(1)$ 即可。

# 分治算法

-   **逆序对计数**
	*   **应用背景**：该算法常用于推荐系统（如协同过滤）中，用来比较两个人对歌曲等事物的排名相似度。两者的排名形成的逆序对越少，口味越相似。
	*   **算法与技巧**：
	    暴力比对需要 $O(n^2)$。分治法巧妙地将其与**归并排序结合**。
	  *   分解：将序列对半拆分。
	  *   解决：递归地计算左右两半各自的逆序对数量。
	  *   合并：计算横跨左右两半的逆序对（即 $a_i$ 在左，$a_j$ 在右，且 $a_i > a_j$）。
	  *   **合并技巧**：我们发现，对于在左边的 $s$ 与在右边的 $t$，如果原来 $(s, t)$ 是/不是一对逆序对，那么，无论左边集合内或者右边集合内元素顺序如何交换，$(s, t)$ 依旧是/不是一对逆序对。
		  * 在分治的过程中归并排序，在合并过程中，使用指针 $i$ 遍历左半部分 $L$，指针 $j$ 遍历右半部分 $R$。如果 $L[i] \le R[j]$，则没有逆序对产生，$i++$；如果 $L[i] > R[j]$，找到一对逆序对，逆序对数目+1，且 $j++$。此技巧使合并的代价降为 $O(n)$，从而使整体时间复杂度降为 $O(n \log n)$。
-   **最近点对问题**
	* **问题描述**：在平面内找出距离（欧几里得距离）最近的两个点。
	* **算法与几何技巧**：
	  * **分解**：画一条垂直中线 $L$，将平面上的点尽可能平分为左右两部分。
	  * **解决**：分别递归求出左右两半区域的最小距离 $\delta_1$ 和 $\delta_2$，并取两者的最小值 $\delta = \min(\delta_1, \delta_2)$。
	  * **合并**：只需寻找是否存在一个点在左边、一个点在右边，且距离小于 $\delta$ 的点对。
	  * **核心证明与优化技巧**：
	    1. **区域修剪**：只需考察距离中线 $L$ 水平距离在 $\delta$ 以内（宽度为 $2\delta$ 的垂直带状区域）的所有点。
	    2. **按 $Y$ 轴扫描**：将带状区域内的点按 $y$ 坐标排序。
	    3. **几何边界限制（Structural Bound）**：证明如果在 $2\delta$ 的带内有两点距离小于 $\delta$，那么在这两个点之间最多只能插入有限的几个点。通过将区域划分为 $\frac{\delta}{2} \times \frac{\delta}{2}$ 的网格，根据鸽巢原理可以证明，**在排序后的列表中，每个点最多只需要往下检查接下来的 11 个相邻点**（因为如果超过11个点，这11个点中必然有两个在同一侧且距离小于 $\delta$，这与 $\delta$ 是各自区域内最小距离的定义矛盾）。
		    -   **引理**：每个小格子里最多只有 1 个点。不然左右两边点之间的最小距离一定小于 $\delta$。
		    -   **找到上界**：由于我们排序时只利用了 y 轴高度这个信息。那么要怎么利用这个高度找到一个搜索点数的上界呢？我们发现，对于高度从小到大第 $i$ 高的点 $i$，如果和在其上面的点 $j$ 至少**相隔** 2 行及以上 ，那么 $i$ 与 $j$ 的高度差一定大于 $\delta$，因为两行的垂直距离已经大于 $\delta$ 了。那么，包括点 $i$ 自己所在的那一行以及与 $j$ 相隔的 2 行，一共 $3$ 行之间最多有 12 个点（根据引理）。所以，最多只需要检查不低于点 $i$ 高度的 11 个点即可。这保证了合并这个过程的时间复杂度是线性的。
	    4. **避免重复排序**：如果在每次递归合并时都对带状区域的点重新排序，总时间为 $O(n \log^2 n)$。为了优化到 $O(n \log n)$，让递归函数不仅仅返回最小距离 $\delta$，还同时返回按 $y$ 坐标排好序的点列表，这样在合并时只需通过一次 $O(n)$ 的归并操作即可获得有序列表，避免了重复排序的开销。
-   **整数乘法（Karatsuba Multiplication）**：
	*   将两个 $n$ 位整数分别拆分为两个 $n/2$ 位的数字。
	*   普通分治法需要做 4 次 $n/2$ 位整数的乘法，得出 $T(n) = 4T(n/2) + O(n) = \Theta(n^2)$。
	*   **优化技巧**：通过巧妙构造 $(x_1 + x_0) \cdot (y_1 + y_0)$，可以用三次乘法推导出所需的四部分信息，从而将子问题数量从 4 减少到 3。
		*   具体地，这里只需要计算 $x_1y_1$，$x_0y_0$ 和 $(x_1+x_0)(y_1+y_0)$ 3 次规模为 $T(\frac{n}{2})$ 的乘法即可。
	*   结果：递推式变为 $T(n) = 3T(n/2) + O(n)$，根据主定理，复杂度优化为 $O(n^{\log_2 3}) \approx O(n^{1.585})$。

-   **矩阵乘法（Strassen's Algorithm）**：
	* 普通分治法将 $n \times n$ 的矩阵拆分为四个 $n/2 \times n/2$ 的子矩阵，需要进行 8 次子矩阵乘法，得出 $T(n) = 8T(n/2) + \Theta(n^2) = \Theta(n^3)$。
	* **优化技巧**：Strassen 通过极其巧妙但复杂的加减法组合，设计了只需要计算 7 个子矩阵乘积的方法（需要18次矩阵加减法）。
	* 结果：递推式变为 $T(n) = 7T(n/2) + \Theta(n^2)$，复杂度优化为 $O(n^{\log_2 7}) \approx O(n^{2.81})$。虽然 Strassen 算法理论上更优，但在实践中（考虑数值稳定性、稀疏性、缓存等）通常在规模 $n \approx 128$ 左右时才比经典算法显示出优势。
