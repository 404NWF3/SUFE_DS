# 动态规划 · 最优性证明套路

# 重点概览

## 核心思想

写出一道 DP 的状态转移方程之后，还要证明它**正确**——即证明递推式算出来的就是真正的最优值。这类证明的标准套路是**强归纳 + 夹逼双向不等式**：

- 命题："$\text{OPT}(i)$ 由这条递推式正确计算"，对归纳量 $i$ 强归纳。
- 上界（$\le$）：拿一个 $i$ 阶段的任一最优解 $A$ 去切，证明它不超过递推式右端。
- 下界（$\ge$）：**另造一个解**，证明存在一个真实可行解能达到（在某些情形上）右端。
- 由 $\le$ 与 $\ge$ 夹逼，得 $\text{OPT}(i)=$ 右端，归纳完成。

这一证法的真正难点不在 ≤ 方向（基本是机械的"删最后一步、套归纳假设"），而在 ≥ 方向：**下界论据不能依赖 $A$，必须另造解**。这一点最易写错，本文单列一节专门说明。

> ⭐ **一句话**：DP 最优性证明 = 强归纳定良序 + 基例 + （删末项套归纳 → 上界）/（另造解达到右端 → 下界）→ 夹逼等号。

## 阅读路线

第 1 节先建立证明的逻辑骨架（设问、归纳方向、夹逼两向各自要做什么）；第 2 节细讲夹逼的 ≤ 与 ≥ 两个方向，重点澄清"为何下界不能依赖 $A$"这个最容易的错误；第 3 节整理贯穿其中的辅助技巧（哨兵、右端是 $j$ 的函数、拼接合法性核验）；第 4 节用第 9 题把全文套路串起来走一遍；第 5 节列易错点与速查表。文中 $\le/\ge$ 方向的措辞统一约定见第 2.1 节开头。

# 1. 证明的逻辑骨架

## 1.1 要证什么

设已写出状态转移方程

$$\text{OPT}(i)=\max_{0\le j<i}\Bigl(F(i,j)\Bigr),\qquad F(i,j)=\text{OPT}(j)+\text{段贡献}(i,j),$$

其中 $F(i,j)$ 表示"上一个分界点是 $j$，从 $j$ 到 $i$ 这一段独立贡献"的形式（具体问题里"分界"可能是重启日、买入日、前驱等）。我们要证的命题分两部分：

**命题 P(i)**：递推式算出的值等于真正的最优值，即对每个 $i$，上式两端相等。

**基例**：$i=0$（或广义的最小归纳量）通常由最优值定义直接成立，例如 $\text{OPT}(0)=0$（空段处理量为 0）或 $\text{OPT}(0)=\text{OPT}(0,0)=0$。

**归纳步**：假设 P(j) 对一切 $j<i$ 成立（强归纳），证明 P(i)。

> ⭐ **命题不是"递推式能算"**，而是"递推式算出的值"恰等于"真正最优值"。这两者相等要靠归纳证明，**不是写出一个递推就自动正确**。很多同学写完递推就假设它对——这跳过了证明里唯一不平凡的那一步。

## 1.2 归纳方向 = 转移图的良序

强归纳要选定一个良序。对 DP 而言，最自然也最常用的良序就是**外层循环的计算顺序**：

- 转移落 $i-1$/$i-2$/$i-4$/$j<i$ ⇒ 从小到大对 $i$ 归纳。
- 转移落 $j>i$（如后缀式 $\text{OPT}(j)=\min_{k\ge j}\dots$）⇒ 从大到小对 $j$ 归纳，否则归纳假设用不上。
- 多维（如 $\text{OPT}(t,i)$）⇒ 按二元组的某个良序（先按 $t$ 再按 $i$，或反之）归纳。
- 非下标归纳量（树形按子树大小、DAG 按拓扑位次、扫描按长度）⇒ 按 DP 计算铺开的那个序。

选错方向会让归纳假设"够不到"要证的当前项。判断口径：递推式右端引用的那些 $\text{OPT}(\cdot)$，必须都是归纳假设已经覆盖的——也就是按计算序更早算出来的那些。

## 1.3 强归纳 vs 弱归纳

强归纳假设"$\text{OPT}(j)$ 对一切 $j<i$ 正确"，弱归纳只假设"$\text{OPT}(i-1)$ 正确"。DP 递推通常回跳不止一步（$j$ 取 $0\dots i-1$ 任意值），所以要用**强归纳**——这样无论最优解在 $A$ 里"上一分界"落在哪个 $j$，都能套上对 $\text{OPT}(j)$ 的归纳假设。

# 2. 夹逼双向不等式

## 2.1 上界方向（$\le$）：拆解 $A$，套归纳假设

设 $\le$方向的目标是 $\text{OPT}(i)\le\text{右端}$，其中"右端"指递推式的 $\max_j F(i,j)$。做法：

1. 取 $i$ 阶段的**任一最优解** $A$（即在"前提条件 $i$"下、达到最优值的那个方案）。
2. $A$ 在 $i$ 之前总有一个**最近分界点** $j$（如第 9 题里 $A$ 中 $i$ 之前的最近重启日）。按 $A$ 实际的 $j$，把 $A$ 切成两段：
   - **后段**：从 $j$ 到 $i$，这一段的贡献只取决于 $j$ 和段内序号 $k$，**与 $j$ 之前的安排无关**。这段贡献恰为 $\text{段贡献}(i,j)$。
   - **前段**：$j$ 及更早的安排构成"前提 $j$"下的一个方案，处理量 $\le\text{OPT}(j)$（**归纳假设**：P(j) 已成立）。
3. 两段独立可加：$\text{OPT 的值}(A)\le\text{OPT}(j)+\text{段贡献}(i,j)=F(i,j)\le\max_{j'}F(i,j')=$ 右端。
4. $A$ 是任一最优解，故 $\text{OPT}(i)=\text{OPT 的值}(A)\le$ 右端。

> ⚠️ **逻辑陷阱 · "A 的前段不一定采纳 OPT(j) 的方案"**
> 第 2 步里写的是 $\text{OPT 的值}(A)\le\text{OPT}(j)$，这是**上界**，恰好因为 $A$ 的前段只是"前提 $j$ 下的某个方案"而非"那个最优方案"——所以只能说不超过 $\text{OPT}(j)$。这里**不能**因为"假定了最优解存在、一定取到 OPT(j)"就轻易宣称 $\text{OPT 的值}(A)=\text{OPT}(j)$，那样会把"还不知道 DP 是否有效"这件事纳入假设，属于循环论证。正确处理是:把 $A$ 的前段当作一般方案,套归纳假设给出的上界即可。

> 💡 上界方向几乎总是机械的。掌握节奏：任取最优解 → 找它在递推里对应的那个 $j$ → 拆前段后段 → 前段套归纳假设给上界、后段直接等于段贡献 → 加起来 $\le$ 右端。

## 2.2 下界方向（$\ge$）：另造一个解

设 $\ge,$方向的目标是 $\text{OPT}(i)\ge$ 右端，这里"右端"作为一个 $j$ 的函数先取最大。做法：

1. 设右端在某 $j=j^\*$ 取得最大：$j^\*=\arg\max_j F(i,j)$。
2. **另造一个解** $B$：取一个真正实现 $\text{OPT}(j^\*)$ 的"前提 $j^\*$"最优方案 $A_{j^\*}$（由归纳假设 P(j*) 成立，它存在），在其后让 $j^\*+1,\dots,i-1$ 按段贡献 $(i,j^\*)$ 所要求的方式连起来、第 $i$ 天做那个"前提 $i$"。这样 $B$ 是一个合法的"前提 $i$"方案，其总处理量恰为 $F(i,j^\*)=\max_j F(i,j)=$ 右端。
3. $\text{OPT}(i)$ 是"前提 $i$"下一切可行方案的最大值，$B$ 是其中一个，故 $\text{OPT}(i)\ge\text{OPT 的值}(B)=$ 右端。

> ⭐ **为何"另造解"是必须的**
> 下界方向论证的是"最优值**至少**不小于右端"。这要求存在一个合法解取到右端。这里**不能**直接拿上界方向里的 $A$ 凑数——$A$ 是为证明上界取的那个特定最优解，它的 $j$ 不一定是 $j^\*$，$\text{OPT 的值}(A)$ 不一定等于 $F(i,j^\*)$。所以下界方法只能另起炉灶：锁定右端取到最大的那个 $j^\*$，**专门为它构造一个解** $B$，证明 $B$ 存在且取到右端，从而 $\text{OPT}(i)\ge$ 右端。

> ⚠️ **常见错误写法（看似自然、实则不严密）**
> 有人会写成："因为 $A$ 能遍历各种 $j$，所以 $A$ 能取到右端最大值，于是 $\text{OPT}(i)\ge$ 右端。" 这问题在于：同一个最优解 $A$ 里 $j$ 只有一个确定值，它**不可能**遍历所有 $j$ 值。"取遍所有 $j$ 中的最大"这个动作是定义右端 $j^\*$ 的 $\arg\max$ 做的，与 $A$ 无关。把"对所有 $j$ 求最大"解释成"一个解遍历所有选择"是范畴错误。

> 💡 **正确的模型**：上界方向是"任何一个最优解 $A$ 都不超过右端"，下界方向是"存在一个解 $B$（另造）取到右端"。两件事的对象不同——一个"$\forall A$"，一个"$\exists B$"——夹起来才能得等号。

## 2.3 夹逼与归纳收尾

由 2.1 得 $\text{OPT}(i)\le$ 右端，由 2.2 得 $\text{OPT}(i)\ge$ 右端，故 $\text{OPT}(i)=$ 右端，即 P(i) 成立。结合对一切 $j<i$ 的强归纳假设，整个强归纳完成。$\blacksquare$

通常还要补一句把递推的最优值接到原问题全局最优上：在末尾做"假想终态"哨兵（见第 3.1 节），让真正的全局最优 $=\text{OPT}(\text{哨兵位置})$，从而递推算的就是答案。第 4 节第 4 步会走一遍。

# 3. 贯穿其中的辅助技巧

## 3.1 哨兵

DP 递推有"起步"和"收尾"两个边界。比在这个地方写一堆 `if i==0` 特判更优雅的做法是设**哨兵**：

- **起点哨兵**：在最小归纳量前虚拟一个状态（如虚拟第 0 天重启、虚拟事件 0、$OPT(0,0)=0$），使递推在 $i=1$ 时右端引用到的 $\text{OPT}(0)$ 有定义且取值自然。基例就只剩"哨兵处空集成立"这一条。
- **终点哨兵**：在末尾虚拟一个"假想终态"（如第 9 题里第 $n+1$ 天虚拟重启），让最后一段无需真正收尾就能被递推计入，使全局最优直接 $=\text{OPT}(\text{位置})$。

> 💡 **哨兵的作用**：让"边界=退化的普通情形"。这样递推式不必 if 分支特判，基例退化成一句 trivial，证明里也少掉一堆边界讨论。

设哨兵时要核验它**不改变原问题**：虚拟重启日不占真实天、不扣处理量，虚拟终态不增添约束。否则哨兵会把原问题偷换成另一个问题。

## 3.2 右端是 $j$ 的函数（下界的关键铺垫）

证明里把右端显式看作 $j$ 的函数 $\text{右端}(j)=F(i,j)$ 而不是单个数，有两大好处：

- 写下界时能自然说出"设右端在 $j=j^\*$ 取到最大"，从而构造解 $B$。
- 论证"对右端每个分支 $F(i,j)$ 单独评估"而不被某个特定的 $A$ 绑住。

这是第 2.2 节"另造解"能够写顺的铺垫：先承认右端随 $j$ 取值有整套可能，再选最大的那个支，再把 $\text{OPT}(j^\*)$ 经归纳假设认作存在，最后组装成 $B$。

## 3.3 拼接合法性核验

下界方向"另造解 $B$"时，是把 $\text{OPT}(j^\*)$ 的方案与后段 $\text{段贡献}(i,j^\*)$ 拼起来。拼接未必天然合法，必须显式核验：

- **间隔合法**：如题 1 路径独立集，若选 $v_i$ 则前一被选点须至少隔 2，$\ge i-2$；若 $j^\*=i-1$ 则相当于"第 $i-1,i$ 相邻两天都重启"，拼接时中间无工作日→贡献为 0，合法但通常不优。
- **可达合法**：如题 3 有序图最长路，要求所选前驱 $i^\*<j$ 且路径仍简单。
- **不重叠合法**：如题 21 多次买卖，要求新交易从 $b$ 天买、$i$ 天卖，与前一笔区间不重叠。

> ⚠️ 拼接合法性是夹逼最易出错处：漏验会让下界方向凭空多出"实际上不存在的可行解"，使等号不成立。每题要在下界构造里显式声明一句拼接为何合法。

# 4. 范例：第 9 题「重启调度」证明

下面把第 9 题完整套上文中的套路，作为贯穿例子。原题、原题翻译、最终伪代码与 (a) 小题实例见 [动态规划最优性证明——我的理解](动态规划最优性证明——我的理解.md)；这里只走"正确性证明"这一走。

**递推（哨兵 $i=0$ 与 $i=n+1$）：**
$$\text{OPT}(i)=\max_{0\le j<i}\Bigl(\text{OPT}(j)+\sum_{k=1}^{i-1-j}\min(x_{j+k},\,s_k)\Bigr),\qquad \text{OPT}(0)=0.$$

**命题 P(i)：** 上式对每个 $i$ 成立（强归纳，$i$ 从小到大）。

**基例。** $\text{OPT}(0)=0$：虚拟第 0 天重启，之前无真实天，处理 0。成立。

**归纳步（$\le$）。** 设 P(j) 对一切 $j<i$ 成立。任取"第 $i$ 天重启"前提下的最优方案 $A$，设 $A$ 中 $i$ 之前的最近重启日是第 $j$ 天。则：

- 后段（$j+1,\dots,i-1$ 天连续工作、第 $i$ 天重启）：贡献 $\sum_{k=1}^{i-1-j}\min(x_{j+k}, s_k)$，只依赖段首 $j$ 与段内序号 $k$，与 $j$ 之前无关。
- 前段（$j$ 及更早）：是"第 $j$ 天重启"前提下的某方案，处理量 $\le\text{OPT}(j)$（归纳假设 P(j)）。

两段可加，$\text{处理量}(A)\le\text{OPT}(j)+\sum_{k=1}^{i-1-j}\min(x_{j+k},s_k)=F(i,j)\le\max_j F(i,j)=$ 右端。$A$ 任取最优解，故 $\text{OPT}(i)\le$ 右端。

**归纳步（$\ge$，另造解）。** 视右端为 $j$ 的函数：$F(i,j)=\text{OPT}(j)+\sum_{k=1}^{i-1-j}\min(x_{j+k}, s_k)$。设其在 $j=j^\*$ 取最大（$j^\*=\arg\max_j F(i,j)$，由取 $0\le j<i$ 的有限选择必存在）。由归纳假设 $\text{OPT}(j^\*)$ 已被正确计算，取一个真正实现它的"第 $j^\*$ 天重启"方案 $A_{j^\*}$；在其后令第 $j^\*+1,\dots,i-1$ 天按段内序号 $k=1\dots i-1-j^\*$ 处理 $\min(x_{j+k},s_k)$、第 $i$ 天重启。所得 $B$ 为合法的"第 $i$ 天重启"方案（拼接合法：$B$ 只是按 $A_{j^\*}$ 规定为前提、再接一段工作，未违反任何重启约束），其处理量恰为 $F(i,j^\*)=$ 右端。故 $\text{OPT}(i)\ge$ 右端。

**收尾。** $\le$ 与 $\ge$ 夹逼得 $\text{OPT}(i)=$ 右端，P(i) 成立。结合强归纳假设，归纳完成。$\blacksquare$

**接到全局最优。** 任意真实可重启方案都对应"在第 $n+1$ 天虚拟重启"前提下的方案（哨兵不改变前 $n$ 天处理量），反之每个这类虚拟前提下方案都真实可行。故全局最优 $=\text{OPT}(n+1)$。

# 5. 易错点与速查表

## 易错点

1. **写完递推就默默认它正确**。递推能算、与递推算的是真正最优值是两回事；后者要靠归纳＋夹逼，不能省。
2. **下界方向拿 $A$ 凑数**。$A$ 的 $j$ 是确定的一个值，不是 $j^\*$；上面 ≥ 方向必须另造一个解 $B$，不能从 $A$ 推。
3. **把"对所有 $j$ 取最大"理解成"一个解遍历所有选择"**。$\arg\max$ 是定义右端做的，与单个解的能力无关。
4. **前段写成 $=\text{OPT}(j)$ 而不是 $\le\text{OPT}(j)$**。上界方向 $A$ 的前段只是某方案，是上界；写成等号相当于假定了 DP 有效，循环论证。
5. **归纳方向选反**。后缀式 $\text{OPT}(j)=\min_{k\ge j}\dots$ 要从大到小对 $j$ 归纳，套小到大归纳会让假设够不到当前项。
6. **删末段后忘了"下标严格更小，归纳假设才够得着"**。这是上界方向套归纳假设的前提。
7. **哨兵改变了原问题**。哨兵须不占真实天、不扣处理量、不增添约束；构造哨兵后要回看一眼它真等价于原问题。
8. **拼接合法性漏验**。尤其多维、带区间/间隔约束的题，$\ge$ 方向拼一段必须显式声明拼接不违反原约束。

## 速查表：DP 最优性证明分层检查单

| 检查项 | 要看的事 |
|------|--------|
| 命题 | "递推算出的值 == 真正最优值"，不是"递推能算" |
| 归纳方向 | 选外层循环序作良序；后缀式从大到小归纳 |
| 强归纳假设 | 覆盖一切 $j<i$ 的 $\text{OPT}(j)$，不只 $\text{OPT}(i-1)$ |
| 基例 | 哨兵处空集 / trivial 成立（如 $\text{OPT}(0)=0$） |
| 上界 $\le$ | 任取最优 $A$→拆前后段→前段套归纳假设 $\text{OPT 的值}\le\text{OPT}(j)$、后段直接 $\text{段贡献}(i,j)$→$\le$ 右端 |
| 下界 $\ge$ | 另造解 $B$：选 $\arg\max_j F(i,j)=j^\*$ → 取实现 $\text{OPT}(j^\*)$ 的方案→接后段→得 $\text{OPT}(i)\ge$ 右端 |
| 拼接合法 | $B$ 的前后段不违反原约束（间隔/可达/不重叠） |
| 收尾 | 哨兵把全局最优 $=\text{OPT}(\text{哨兵位置})$，且哨兵不改变原问题 |
