## 深度学习任务的五要素框架

任何一个深度学习任务，无论多么复杂，都可以被分解为五个正交的组件。它们之间的关系不是扁平的"先做 A 再做 B"，而是系统的、相互制约的：

```
┌──────────────────────────────────────────────────────────┐
│                     深度学习系统                            │
│                                                            │
│   数据 ──→ 模型 ──→ 损失函数 ──→ 优化器 ──→ 评估指标          │
│    ↑                                  ↓                    │
│    └────────────── 训练循环 ────────────┘                    │
│                                                            │
│   五要素的职责分工:                                           │
│   · 数据定义了性能的"天花板"（特征工程 + 质量）                  │
│   · 模型定义了表达能力的"假设空间"（你能逼近多复杂的函数）         │
│   · 损失函数定义了"什么是对的"（优化目标 = 裁判）                │
│   · 优化器决定了"能否到达目标"（搜索策略）                      │
│   · 评估指标决定了"这真的有用吗"（业务目标）                     │
└──────────────────────────────────────────────────────────┘
```

### 为什么是五个，不是四个也不是六个？

你可能会问：难道不能把"损失函数"和"评估指标"合并吗？或者把"模型"和"损失"合并成"目标函数"吗？

答案是：**不能**。因为它们各自解答的是完全不同的问题，且在实际工程中由不同角色负责：

| 要素 | 解答的问题 | 负责人 |
|---|---|---|
| 数据 | 我们要学什么？数据够不够？有没有噪声？ | 数据工程师 / 标注团队 |
| 模型 | 我们能学多复杂的模式？ | 算法研究员 |
| 损失函数 | 在训练时，什么算"好"？ | 算法研究员 |
| 优化器 | 怎么找到"好"的参数？ | MLEngineer / 研究员 |
| 评估指标 | 产品上，什么算"好"？ | 产品经理 + 研究员 |

**损失函数 ≠ 评估指标**是一个极其重要但经常被忽略的区分。损失函数必须是**可导的**（用于反向传播），评估指标必须是**与业务对齐的**（但可以不可导）。后文会详细展开。

## 完整代码：先给全貌，再逐行解剖

```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt
from torch.utils.data import DataLoader, TensorDataset

# ============================================================
# 0. 全局配置（可复现性）
# ============================================================
torch.manual_seed(42)

# ============================================================
# 第一步：数据生成与划分
# ============================================================
def generate_synthetic_data(n=100, w_true=2.0, b_true=1.0, noise_std=0.5):
    """
    生成 y = 2x + 1 + ε 的带噪数据

    为什么加噪声？
    现实世界没有完美的线性关系。噪声的存在使问题不平凡——
    如果 y = wx + b 精确成立，两个点就求出唯一解；
    有了噪声，才需要"从多个样本中估计最优参数"。

    噪声的统计意义:
      ε ~ N(0, σ²)，那么 y|x ~ N(wx + b, σ²)
      最小化 MSE ⟺ 最大化似然（在高斯噪声假设下）
    """
    X = torch.rand(n, 1) * 10                          # (n, 1), 均匀分布 [0, 10]
    epsilon = torch.randn(n, 1) * noise_std             # (n, 1), 高斯噪声
    y = w_true * X + b_true + epsilon
    return X, y

X, y = generate_synthetic_data(n=100)

# 划分：train 60 / val 20 / test 20
n = len(X)
idx = torch.randperm(n)
train_idx, val_idx, test_idx = idx[:60], idx[60:80], idx[80:]
X_train, y_train = X[train_idx], y[train_idx]
X_val,   y_val   = X[val_idx],   y[val_idx]
X_test,  y_test  = X[test_idx],  y[test_idx]

train_loader = DataLoader(TensorDataset(X_train, y_train), batch_size=8, shuffle=True)

# ============================================================
# 第二步：模型定义
# ============================================================
class LinearRegression(nn.Module):
    """
    y_pred = x · w + b

    这是一个只有两个参数 (w, b) 的假设空间。
    所有可能的直线构成了我们要搜索的空间。

    Parameter vs Tensor 的区别:
      - nn.Parameter 是 Tensor 的子类
      - 唯一区别：出现在 nn.Module 的 parameters() 迭代器中
      - 这意味着 optimizer 知道"这个 requires_grad=True 的 tensor 需要更新"
    """
    def __init__(self):
        super().__init__()
        self.w = nn.Parameter(torch.randn(1, 1) * 0.1)  # 小值初始化
        self.b = nn.Parameter(torch.zeros(1))

    def forward(self, x):
        return x @ self.w + self.b

model = LinearRegression()

# ============================================================
# 第三步：损失函数
# ============================================================
loss_fn = nn.MSELoss()   # ℓ(w,b) = 1/n · Σ(wx_i + b - y_i)²

# ============================================================
# 第四步：优化器 + 学习率调度
# ============================================================
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=500, gamma=0.5)

# ============================================================
# 第五步：训练循环
# ============================================================
n_epochs = 2000
train_losses, val_losses = [], []

for epoch in range(1, n_epochs + 1):
    # ------ 训练阶段 ------
    model.train()
    epoch_train_loss = 0.0
    for X_batch, y_batch in train_loader:
        y_pred = model(X_batch)                         # ① 前向传播
        loss = loss_fn(y_pred, y_batch)                 # ② 计算损失

        optimizer.zero_grad()                           # ③ 清零历史梯度
        loss.backward()                                 # ④ 反向传播
        optimizer.step()                                # ⑤ 参数更新

        epoch_train_loss += loss.item() * len(X_batch)

    scheduler.step()                                    # ⑥ 调整学习率

    # ------ 评估阶段 ------
    model.eval()
    with torch.no_grad():
        y_val_pred = model(X_val)
        val_loss = loss_fn(y_val_pred, y_val).item()

    train_losses.append(epoch_train_loss / len(X_train))
    val_losses.append(val_loss)

    if epoch % 400 == 0:
        print(f"Epoch {epoch:4d} | Train Loss: {train_losses[-1]:.6f} | "
              f"Val Loss: {val_loss:.6f} | w: {model.w.item():.4f} | b: {model.b.item():.4f}")

# ============================================================
# 第六步：最终评估
# ============================================================
model.eval()
with torch.no_grad():
    y_test_pred = model(X_test)
    test_loss = loss_fn(y_test_pred, y_test).item()

    # R² = 1 - SS_res / SS_tot
    ss_res = torch.sum((y_test - y_test_pred) ** 2)
    ss_tot = torch.sum((y_test - y_test.mean()) ** 2)
    r2 = 1 - ss_res / ss_tot

print(f"\n{'='*50}")
print(f"  真实值: w=2.0, b=1.0")
print(f"  预测值: w={model.w.item():.4f}, b={model.b.item():.4f}")
print(f"  Test Loss (MSE): {test_loss:.6f}")
print(f"  Test R²:         {r2:.4f}")
print(f"{'='*50}")
```

## 各要素深度拆解

### 一、数据：特征矩阵与设计矩阵

数据不是"装样本的容器"，它有严格的层次结构：

```
数据的四个层次:
┌─────────────────────────────────────────────┐
│  数据集 (Dataset)                             │
│  ├── 训练集 (Training)    60-80%  ← 学习参数  │
│  ├── 验证集 (Validation)  10-20%  ← 调超参数  │
│  └── 测试集 (Test)        10-20%  ← 最终评估  │
├─────────────────────────────────────────────┤
│  每个样本 (Sample) = (特征向量, 标签)          │
│  特征 (features / X): 输入变量                 │
│  标签 (labels / y):     要预测的目标            │
│  噪声 (noise):         永远存在，不可约减误差    │
└─────────────────────────────────────────────┘
```

#### 设计矩阵的维度约定

PyTorch 的数据维度有一套**死记硬背也不够**的约定：

```python
# 设计矩阵 X: (n_samples, n_features)
#   第一维始终是"样本数"（batch 维）
#   第二维是"特征数"
# 标签 y: (n_samples,) 或 (n_samples, 1)
#   回归通常是一维标量

X = torch.randn(100, 3)    # 100 个样本，每个 3 个特征
y = torch.randn(100, 1)    # 100 个样本，每个一个回归目标

# 错误的维度顺序 vs 正确的:
# ❌ X = (3, 100) → 广播会完全错乱，且无声
# ✅ X = (100, 3)
```

在线性回归中：
$$y_i = w_1 x_{i1} + w_2 x_{i2} + \cdots + w_d x_{id} + b + \varepsilon_i = \mathbf{x}_i^\top \mathbf{w} + b + \varepsilon_i$$

向量化形式（实际在 GPU 上并行计算的形式）：
$$\mathbf{y} = \mathbf{X} \mathbf{w} + b \cdot \mathbf{1}_n + \boldsymbol{\varepsilon}$$

### 二、模型：假设空间与表达能力

模型定义了一个**假设空间** $\mathcal{H}$——所有可能的输入到输出映射的集合：

$$\mathcal{H} = \{f_\theta \mid \theta \in \Theta\}$$

- $\theta$：可训练参数（线性回归中是 $w$ 和 $b$）
- $\Theta$：参数空间（线性回归中是 $\mathbb{R} \times \mathbb{R}$）
- $f_\theta$：具体的一个函数 / 假设 / 模型实例

#### 表达能力的关系链

```
             参数数量            表达能力                 拟合能力
线性回归:     (d+1)             → 只能拟合超平面            低 bias, 高 variance? 不对

关键纠正: 这里的 direction 是相反的——
             参数越少               → bias 高 (欠拟合风险大)
             参数越多               → variance 高 (过拟合风险大)

正确的 bias-variance 方向:
  简单模型 (线性)  ─→  高 bias, 低 variance
  复杂模型 (深层)  ─→  低 bias, 高 variance
```

**核心洞察**：更大的假设空间 = 更强的拟合能力 = 更低的理论偏差（bias） = 更高的过拟合风险（variance）。这是一条不可突破的 trade-off。

#### `nn.Parameter` vs `torch.Tensor` 的本质区别

```python
# nn.Parameter 的源码简化版
class Parameter(torch.Tensor):
    def __new__(cls, data=None, requires_grad=True):
        if data is None:
            data = torch.empty(0)
        return torch.Tensor._make_subclass(cls, data, requires_grad)

# 作用: 出现在 model.parameters() 中
for name, param in model.named_parameters():
    print(f"{name}: {param.shape}")  # w: (1, 1), b: (1,)

# 而普通 tensor 即使 requires_grad=True 也不会出现在这里
# optimizer 只更新 model.parameters() 中的参数
```

### 三、损失函数：MSE 的统计解释与偏差-方差分解

#### MSE 的三种等价定义

$$ \ell(\mathbf{w}, b) = \frac{1}{n} \sum_{i=1}^n \left( \hat{y}_i - y_i \right)^2 \tag{定义 1: 平均平方误差 $$

$$ \ell(\mathbf{w}, b) = \frac{1}{n} \|\hat{\mathbf{y}} - \mathbf{y}\|_2^2 \tag{定义 2: L2 范数 $$

$$ \ell(\mathbf{w}, b) = \mathbb{E}_{\hat{p}}\left[(\hat{y} - y)^2\right] \tag{定义 3: 经验期望 $$

#### 为什么多层网络也用 MSE 做回归，但分类用 CrossEntropy？

这是一个好问题，答案藏在**似然函数**里：

- **回归**：假设 $y \mid \mathbf{x} \sim \mathcal{N}(f_\theta(\mathbf{x}), \sigma^2)$，最大化对数似然 $\Leftrightarrow$ 最小化 MSE
- **分类**：假设 $y \mid \mathbf{x} \sim \text{Categorical}(\text{softmax}(f_\theta(\mathbf{x})))$，最大化对数似然 $\Leftrightarrow$ 最小化 CrossEntropy

MSE 用于分类的问题是：sigmoid + MSE 会导致梯度饱和（sigmoid 输出接近 0 或 1 时梯度趋近 0），CrossEntropy 配合 sigmoid/softmax 的对数运算消掉了这个饱和效应——这是 Logistic 回归的经典结果。

#### 偏差-方差分解（完整的数学推导）

对任意测试点 $\mathbf{x}_0$，期望预测误差可以分解为：

$$\mathbb{E}_{\mathcal{D}, \varepsilon}\left[(y_0 - \hat{f}(\mathbf{x}_0))^2\right] = \underbrace{\left(\mathbb{E}[\hat{f}(\mathbf{x}_0)] - f(\mathbf{x}_0)\right)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}\left[(\hat{f}(\mathbf{x}_0) - \mathbb{E}[\hat{f}(\mathbf{x}_0)])^2\right]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{不可约减噪声}}$$

推导过程（对想深入理解的人很重要）：

设真实模型为 $y = f(\mathbf{x}) + \varepsilon$，其中 $\mathbb{E}[\varepsilon]=0$，$\text{Var}(\varepsilon)=\sigma^2$。用同一个算法在不同训练集 $\mathcal{D}$ 上学到的函数记为 $\hat{f}_{\mathcal{D}}$。

$$\begin{aligned} \mathbb{E}[(y - \hat{f})^2] &= \mathbb{E}[(f + \varepsilon - \hat{f})^2] \\ &= \mathbb{E}[(f - \hat{f})^2] + \mathbb{E}[\varepsilon^2] + 2\mathbb{E}[\varepsilon(f - \hat{f})] \\ &= \mathbb{E}[(f - \hat{f})^2] + \sigma^2 \quad (\because \varepsilon \perp \mathcal{D}) \\ &= \mathbb{E}[(f - \mathbb{E}[\hat{f}] + \mathbb{E}[\hat{f}] - \hat{f})^2] + \sigma^2 \\ &= (f - \mathbb{E}[\hat{f}])^2 + \mathbb{E}[(\mathbb{E}[\hat{f}] - \hat{f})^2] + \sigma^2 \quad (\because \text{交叉项期望为 0}) \\ &= \text{Bias}^2 + \text{Variance} + \sigma^2 \end{aligned}$$

这就解释了为什么**只看 loss 下降不够**——你需要同时观察训练 loss 和验证 loss，来判断下降来自于降低 bias 还是降低 variance。

```
验证 loss 的四种形态:

loss ↑
  │  train: ↘    val: ↗      → 过拟合 (高 variance)
  │  train: →    val: →      → 欠拟合 (高 bias)
  │  train: ↘    val: ↘      → 继续训练!
  │  train: →←   val: →←     → 学习率太大，震荡
  └──────────────────────────→ epoch
```

### 四、优化器：从 SGD 到 Adam 的进化逻辑

优化器是"把损失函数降到最低"的策略，它的本质是搜索：

$$\theta^* = \arg\min_{\theta \in \Theta} \ell(\theta)$$

#### 进化谱系

```
SGD (1951)
  θ ← θ - lr · ∇ℓ(θ)
  问题: 峡谷震荡，鞍点困住，高方差

SGD + Momentum (1964)
  v ← βv + ∇ℓ(θ)
  θ ← θ - lr · v
  本质: 用指数移动平均累积过去梯度的"惯性"
  β ≈ 0.9: 过去 10 步梯度的平均

AdaGrad (2011)
  G ← G + ∇ℓ²       (逐元素)
  θ ← θ - lr · ∇ℓ / (√G + ε)
  本质: 频繁更新的参数 → 学习率自动减小
  问题: G 单调递增 → 学习率最终 → 0

RMSprop (2012, Hinton)
  G ← βG + (1-β)∇ℓ²   (指数移动平均替代累加)
  θ ← θ - lr · ∇ℓ / (√G + ε)
  本质: 用 EMA 解决 AdaGrad 的衰减问题

Adam (2014) = Momentum + RMSprop
  m ← β₁m + (1-β₁)∇ℓ      (一阶矩估计, 动量)
  v ← β₂v + (1-β₂)∇ℓ²     (二阶矩估计, 自适应学习率)
  m̂ ← m / (1-β₁ᵗ)          (偏差修正)
  v̂ ← v / (1-β₂ᵗ)
  θ ← θ - lr · m̂ / (√v̂ + ε)

AdamW (2017) = Adam + 解耦的权重衰减
  θ ← θ - lr · (m̂ / (√v̂ + ε) + λθ)    ← 关键: weight decay 不在梯度里
```

#### 为什么 Adam 是默认选择？

Adam 解决了 SGD 的三个核心痛点：
1. **学习率选择困难**：自适应每个参数的学习率
2. **鞍点困住**：动量 + 自适应 = 更容易逃离
3. **不同参数的梯度尺度差异**：二阶矩的倒数自动归一化

但 Adam 也有代价：**泛化性通常不如仔细调过的 SGD**（尤其在图像分类任务中）。这是因为 Adam 的自适应性倾向于找到"尖锐的极小值"——这些解在测试集上泛化更差。

### 五、评估指标：为什么损失 ≠ 评估

这是理解深度学习最关键的分离：

```
损失函数 (Loss): 用于训练
  · 必须可导 → 反向传播需要
  · 是"代理目标"——我们希望降低它就是提升模型
  · 不必与业务目标完全对齐

评估指标 (Metric): 用于衡量
  · 可以不可导 → 不需要反向传播
  · 是"真实目标"——直接对应用户关心的事
  · 必须与业务目标完全对齐
```

经典例子：

| 任务 | 损失函数 | 评估指标 | 为什么不一致 |
|---|---|---|---|
| 线性回归 | MSE | R² / RMSE | RMSE 和 y 同量纲，更直观 |
| 推荐系统 | BCE / MSE | NDCG@10 | 排序质量不可导 |
| 目标检测 | Smooth-L1 | mAP (IoU 匹配) | IoU 不可导 |
| 机器翻译 | CrossEntropy | BLEU | n-gram 匹配不可导 |
| 分类 | CrossEntropy | Accuracy / F1 | 类别不平衡下的正确率不可导 |

R² 的深层含义：$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2} = 1 - \frac{\text{MSE}}{\text{Var}(y)}$$

- $R^2 = 1$：完美预测
- $R^2 = 0$：模型等价于一个"预测均值"的 baseline
- $R^2 < 0$：模型比"预测均值"还差

---

## 训练循环的数学本质

训练循环不是一段"套路代码"，而是**一个优化算法的完整执行**。我们逐行解剖：

```python
for X_batch, y_batch in train_loader:     # 按 mini-batch 迭代
    y_pred = model(X_batch)               # ① 前向传播
    loss = loss_fn(y_pred, y_batch)       # ② 计算标量损失
    optimizer.zero_grad()                 # ③ 清零梯度（累加 vs 清零？）
    loss.backward()                       # ④ 反向传播（自动微分）
    optimizer.step()                      # ⑤ 更新参数
```

### 为什么 `optimizer.zero_grad()` 是必须的？

PyTorch 的 `.backward()` **累加**梯度而不是覆盖——这是有意为之的设计：

```python
x = torch.tensor([2.0], requires_grad=True)
y = x * x
y.backward()
print(x.grad)  # tensor([4.0])   (dy/dx = 2x = 4)

# 如果再次 backward 而不 zero_grad:
y = x * x
y.backward()
print(x.grad)  # tensor([8.0])   (4 + 4 = 8, 累加了!)
```

累加机制的好处是：可以将一个 batch 拆分为多次 backward 再统一 step（相当于隐式扩大 batch size）。但大多数情况下我们不想要累加，所以我们显式清零。

### 广播在训练中的作用

广播机制（详见本文附录 B）在前向和反向传播中同时起作用：

```python
# 前向: y_pred = x @ w + b
#   x: (n, 1)  或 (batch_size, 1)
#   w: (1, 1)
#   b: (1,)     —→ 广播为 (n, 1) 再做加法

# 反向: ∂loss/∂b 通过广播的"反向"来计算
#   ∂loss/∂y_pred: (n, 1)
#   ∂y_pred/∂b:    沿 batch 维 sum → (1,)
#   这就是为什么 broadcast 的梯度 = sum along the broadcasted dimension
```

验证广播的梯度规则：

```python
x = torch.tensor([[1.0], [2.0], [3.0]], requires_grad=True)  # (3, 1)
y = x.expand(3, 5)                                             # (3, 5) via broadcast
z = y.sum()
z.backward()
print(x.grad)  # tensor([[5.], [5.], [5.]])
# x 的每个元素在 y 中"复制"了 5 次 → 梯度 = 5×1 = 5
```

### 对 `loss.backward()` 的完整理解

线性回归中，`loss.backward()` 计算了：

$$\frac{\partial \ell}{\partial w} = \frac{2}{n} \sum_{i=1}^n (wx_i + b - y_i) \cdot x_i$$

$$\frac{\partial \ell}{\partial b} = \frac{2}{n} \sum_{i=1}^n (wx_i + b - y_i)$$

这不是用手算的（在深层网络中你也算不出来），而是通过**反向累计**（reverse-mode automatic differentiation）自动完成——参见 [自动微分的两种模式：前向累计 vs 反向累计](concepts/自动微分.md) 中的完整推导。

## 关键认知升级

### 跳跃一：从线性到非线性的本质

```python
# 线性回归:
y = x @ w + b                    # 只能拟合超平面

# 加一个激活函数 = 质的飞跃:
y = ReLU(x @ w1 + b1) @ w2 + b2  # 通用近似器 (Universal Approximation Theorem)

class NonlinearModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 1)
        )
    def forward(self, x):
        return self.net(x)
```

**无激活函数的多层网络 ≡ 单层线性网络**（数学上等价，因为线性函数复合仍是线性函数）。

**有激活函数**：一个足够宽的单隐藏层网络在理论上可以逼近任意连续函数（Universal Approximation Theorem）。实践中，深度比宽度更高效。

### 跳跃二：从全批量到小批量的权衡

```python
# 全批量梯度下降 (Batch GD):
#   每次用全部训练数据计算梯度 → 精确但昂贵
y_pred = model(X_train_all)        # X: (100000, d)
loss = loss_fn(y_pred, y_train_all)

# 小批量随机梯度下降 (Mini-batch SGD):
#   每次用一个子集估计梯度 → 有噪声但高效
for X_batch, y_batch in dataloader:  # X_batch: (32, d)
    ...

# 小批量的三重角色:
# ① 计算效率: GPU 在 batch=32-256 时吞吐量最大
# ② 随机性正则化: 梯度噪声帮助逃离尖锐极小
# ③ 内存约束: 无法一次加载 100GB 的数据
```

**重要直觉**：SGD 的噪声不是 bug，是 feature。它让优化器不容易困在尖锐的、泛化差的局部极小值中。

### 跳跃三：从手动梯度到自动微分

我们推导出线性回归中 loss 对 w 的梯度是 $\frac{2}{n}\sum (wx_i + b - y_i) x_i$ ——但如果模型是 1000 层 Transformer，没人能写出梯度了。

**可微编程**：你把模型表达为一系列可微操作的组合，框架自动管理所有梯度。PyTorch 的 `autograd` 是一个图构建引擎。它在每步动态构建一个有向无环图（DAG），记录张量与张量之间的所有操作链。反向传播时，它沿着这个图的逆向拓扑序逐节点调用本地梯度函数，通过链式法则累积出最终梯度。由于图是在每次 `forward()` 调用时动态重建的，这也被称为 **define-by-run** ——这也是 PyTorch 和 TensorFlow 1.x 的静态图之间最本质的架构差异。

## 核心心智模型：深度学习工程师的直觉

这些不是"最佳实践"，而是**调试直觉**——当你面对一个不 work 的模型时，这些直觉会告诉你从哪里下手：

1. **先让模型过拟合一个小批量**。用 4 个样本，去掉所有正则化，看 loss 能否降到 0.0001 以下。如果不能，说明模型有结构性 bug，加数据也没用。

2. **学习率是唯一最重要的超参数**。先找合适的学习率量级：尝试 `[1e-1, 1e-2, 1e-3, 1e-4]`，选让 loss 在头 100 步平稳下降且不发散的那个。其他超参数在调对学习率之后再动。

3. **不要期望一次跑通**。训练 DL 模型 = 科学方法：观察 loss → 形成假设 → 修改代码 → 再次观察 loss。每轮迭代的目标是获得关于问题的更多信息，而不是直接得到好结果。

4. **从简单到复杂**。新任务的第一件事：用线性模型（如 Logistic Regression）做 baseline。这个 baseline 告诉你"数据的天然可解性"——如果简单模型就表现不错，说明数据质量好、信噪比高。后续每一步改进都应该有清晰的收益归因。

5. **跟踪梯度范数**。如果某一层的梯度范数突然趋近 0（梯度消失）或爆炸到 1000+，你的损失曲线再漂亮也是虚假的——某些层根本没在学或学疯了。

6. **所有的 DL bug 最终表现为 loss 不下降或 NaN**。当 loss 不正常时，沿着数据流从源头排查：
   - 数据范围是否合理？（有 NaN 或 Inf 吗？）
   - 前向输出是否合理？（有异常值吗？）
   - 损失值是否合理？（初始 loss 应该在对数似然的合理范围内）
   - 梯度是否合理？（每层的梯度范数是否在合理区间？）

7. **测试集只能用来评估一次**。如果你反复在测试集上改策略，它就已经变成验证集了——你正在"污染"你的最终估计。

## 附录 A：线性回归中手算梯度 vs Autograd 的完整推导

### 手算梯度

损失函数：
$$\ell(w,b) = \frac{1}{n} \sum_{i=1}^n (wx_i + b - y_i)^2$$

对 $w$ 求偏导：
$$\frac{\partial \ell}{\partial w} = \frac{1}{n} \sum_{i=1}^n 2(wx_i + b - y_i) \cdot x_i = \frac{2}{n} \sum_{i=1}^n (wx_i + b - y_i) \cdot x_i$$

对 $b$ 求偏导：
$$\frac{\partial \ell}{\partial b} = \frac{1}{n} \sum_{i=1}^n 2(wx_i + b - y_i) \cdot 1 = \frac{2}{n} \sum_{i=1}^n (wx_i + b - y_i)$$

### Autograd 计算图视角

```
前向传播的计算图:
  x ──┐
       ├──→ × (mul) ──→ + (add) ──→ - (sub) ──→ ² (pow) ──→ mean ──→ loss
  w ──┘     ↑            ↑                      ↑
             │            │                      │
  b ────────┘            y ──────────────────────┘

反向传播 (从右到左):
  ∂loss/∂(y_pred - y)²  = 1/n
  ∂loss/∂(y_pred - y)   = 2/n · (y_pred - y)
  ∂loss/∂y_pred         = 2/n · (y_pred - y)
  ∂loss/∂w              = ∂loss/∂y_pred · x  (广播: 每个样本贡献累加)
  ∂loss/∂b              = ∂loss/∂y_pred · 1  (广播: 所有样本求和)
```

### 验证 Autograd 结果

```python
# 手动算梯度
w, b = torch.tensor([2.0], requires_grad=True), torch.tensor([1.0], requires_grad=True)
X = torch.tensor([[1.0], [2.0], [3.0]])
y = 2 * X + 1  # 完美线性关系 (无噪声)

y_pred = X @ w + b
loss = torch.mean((y_pred - y) ** 2)
loss.backward()

# 手算验证:
# w=2, b=1, y_pred=y → loss=0
# ∂ℓ/∂w = (2/3) · Σ(wx_i+b-y_i) · x_i = 0
# ∂ℓ/∂b = (2/3) · Σ(wx_i+b-y_i) = 0
print(f"∂ℓ/∂w (autograd): {w.grad}, 期望: 0")
print(f"∂ℓ/∂b (autograd): {b.grad}, 期望: 0")
```

## 附录 B：广播机制的完整速查表

广播规则（从右往左逐维比较，取最大值）：

| 张量 A 形状 | 张量 B 形状 | 结果形状 | 有效？ | 说明 |
|---|---|---|---|---|
| `(3,)` | `()` | `(3,)` | ✅ | 标量广播到任意形状 |
| `(3, 1)` | `(1, 3)` | `(3, 3)` | ✅ | 典型的"外积式"广播 |
| `(4, 3, 2)` | `(3, 2)` | `(4, 3, 2)` | ✅ | B 被自动左补为 (1, 3, 2) |
| `(4, 3, 2)` | `(3, 1)` | `(4, 3, 2)` | ✅ | 中间的 1 扩展为 2 |
| `(4, 3, 2)` | `()` | `(4, 3, 2)` | ✅ | 标量在整个形状上复制 |
| `(4, 3, 2)` | `(4, 1)` | ❌ | | 第 1 维 a[2] = 2 vs b[1] 缺失 → b 补成 (1, 4, 1) → 3 ≠ 4 |
| `(2, 3)` | `(3, 2)` | ❌ | | 第 1 维 2 ≠ 3，且都不是 1 |
| `(16, 1, 5)` | `(16, 3, 5)` | `(16, 3, 5)` | ✅ | 第 1 维的 1 扩展为 3 |

广播在深度学习中无处不在：

```python
# ① Bias 在 batch 维广播
x = torch.randn(32, 128)       # (batch, features)
w = torch.randn(128, 64)       # (features, hidden)
b = torch.randn(64)            # (hidden,) → 广播到 (32, 64) 或 (1, 64)
out = x @ w + b                # b 在每个样本上自动复制

# ② BatchNorm 的 γ 和 β 在 batch 维和空间维广播
x = torch.randn(32, 64, 28, 28)   # (batch, channel, H, W)
gamma = torch.randn(64)           # (channel,) → 广播到 (32, 64, 28, 28)

# ③ 序列模型中的 mask 广播
seq = torch.randn(32, 128, 512)       # (batch, seq_len, d_model)
mask = torch.ones(128, 128)           # (seq_len, seq_len) 注意力 mask
# mask 自动广播到 (32, 128, 128)
```

**广播的梯度规则**：被广播的维度梯度被 sum reduce：

```python
x = torch.randn(3, 1, requires_grad=True)   # 被广播的源 (第 1 维 = 1)
y = x.expand(3, 5)                           # 广播后的结果
loss = y.sum()
loss.backward()
# ∂y/∂x: 在 y 中每个 x_i 被用到 5 次 → grad 是 5 次 ∂loss/∂y_j 的和
print(x.grad)  # 全是 5 = Σ_j ∂loss/∂y_ij
```

## 附录 C：常见调试清单

### loss 不下降
- [ ] 学习率是否太小？试试 ×10
- [ ] 学习率是否太大？（loss 震荡而不是稳步下降）
- [ ] 数据归一化了吗？（没有归一化 = 不同特征的梯度尺度可能差几个数量级）
- [ ] 梯度消失？（深层网络；打印各层 gradient norm）
- [ ] batch size 是否太小？（梯度估计方差太大）
- [ ] 用简单 batch 过拟合测试了吗？（模型本身是否可学）

### loss = NaN
- [ ] 学习率太大 → 参数爆炸 → 数值溢出
- [ ] 数据中有 NaN 或 Inf → 检查数据加载
- [ ] 损失函数中的除零 → 检查边界情况
- [ ] 梯度爆炸 → 打印 gradient norm
- [ ] 尝试 gradient clipping: `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)`

### 过拟合（train loss ↘，val loss ↗）
- [ ] 加正则化：weight decay (L2), dropout
- [ ] 更多数据 / 更强的数据增强
- [ ] 更小的模型（减少宽度/深度）
- [ ] 早停 (Early Stopping)
- [ ] BatchNorm 反而可能加剧？检查是否在小 batch 下不稳定

### 欠拟合（train loss 和 val loss 都不下降）
- [ ] 更大的模型（更多层 / 更宽）
- [ ] 更弱的正则化
- [ ] 检查模型是否正确实现了你想要的结构
- [ ] 增加训练时间
- [ ] 特征工程是否缺失了关键特征？

### 训练不稳
- [ ] batch size 太小？增大可以降低梯度方差
- [ ] 降低学习率
- [ ] 换用 Adam（比 SGD 更稳定）
- [ ] 使用学习率 warmup（头几百步逐步增大学习率）
- [ ] 检查是否有层的初始化不恰当（输出/梯度过大或过小）

### 测试集效果远差于验证集
- [ ] 测试集与训练/验证集的分布不同？（数据漂移 / 标签偏移）
- [ ] 你用测试集调过参了？（"用过了" = 污染了）
- [ ] 训练/验证/测试集的划分是否随机？（是否是 IID？）
- [ ] 数据增强在测试时关了吗？
- [ ] Dropout/BatchNorm 在推理时正确设置了 `model.eval()` 吗？
