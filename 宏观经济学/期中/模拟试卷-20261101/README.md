## 出题时明确的口径

- 劳动力计算题明确说明停止求职者来自“初始失业者”，并将两种情景设为独立，避免同一人被重复计算。
- 财政政策题明确给出消费反应，先比较同一利率下的储蓄变化，再判断供给曲线移动；不把曲线的水平位移量直接当成均衡投资的变化量。
- 银行题区分实际准备金率与法定准备金率，以及资产／权益杠杆率与货币乘数。
- 银行贷款损失题将“负账面权益及其变化率”和“有限责任下原股东本金损失比例”分别设问。
- 数量方程明确流通速度与实际产出的条件；基期为 100 的 GDP 平减指数与基期为 1 的价格水平分开使用。
